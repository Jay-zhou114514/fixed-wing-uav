# EXP-FW-V1-30 预注册：F_future 估计器的解析互验（S0）

- 日期：2026-09-17
- 状态：**在运行实验之前冻结**（本文件先于任何 EXP-FW-V1-30 结果提交）
- 依据：`RESEARCH_PLAN_v1.2.md` 第 5 节执行阶梯 S0
- 前置：无。本实验是 v1.2 主线的第一个实验

## 0. 为什么先做这个

v1.2 的全部结论都建立在一个前提上：**F（未来可行空间）能被正确测量**。
如果估计器本身有偏差，后续所有"两个动作的 F 有差异"的结论都无法解释——
分不清是机制不存在，还是估计器坏了。

因此本实验**不做任何决策比较**，只做一件事：
**在解析可解的场景下，验证 F-1 与 F-2 两个估计器与解析解一致。**

这是 S0 的出口条件，也是整个 Phase 0 的第一块砖。

## 1. 研究问题

> 在无风、无障碍、常速的解析可解场景下，
> F-1（可行机动计数）与 F-2（可达网格体积）两个估计器，
> 是否与解析计算的未来可达集一致？

## 2. 解析基准（必须先解析导出，再与数值比较）

场景：无风（w = 0）、无障碍、常速 Va、最大转弯率 ω。

从状态 (x₀, y₀, ψ₀) 出发，时间 τ 内可达的非完整可达集为
**Dubins 可达区域**，其边界由三族曲线构成：

```text
(k, 0, k) 型：终末转弯段，半径 R = Va/ω      —— 内边界
(0, k, 0) 型：直段 + 单侧转弯，半径 2R       —— 中边界
(k, k, k) 型：连续转弯（极限为圆）            —— 外边界（半径 R 的圆，圆心偏移）
```

时间 τ 与弧长的关系：总路径长度 L = Va·τ。

**解析量（用于比较）**：

| 符号 | 定义 | 解析可算性 |
| --- | --- | --- |
| `V_analytic(τ)` | 时间 τ 内可达集合的面积 | 可由 Dubins 三族边界解析积分得到 |
| `N_maneuver_analytic(τ)` | 落于可达集内的词表机动个数 | 逐词表元素判定（解析） |
| `A_swept(τ)` | 时间 τ 内的地面扫掠集面积 | EXP-FW-V1-02 的地面曲率式给出，w=0 时退化为经典结果 |

**关键**：w = 0 是**解析可解**的，因此这是唯一能做事前互验的场景。
**不得**在有风场景下做"解析互验"——那里没有闭式解。

## 3. 数值估计器

| 代号 | 定义 | 实现 |
| --- | --- | --- |
| **E1（F-1 档）** | 执行机动 m 后，词表中仍满足"不越界"的机动个数 | 逐元素前向仿真 + 可行性判定 |
| **E2（F-2 档）** | 动作后可达状态集的网格体积 | (x, y, ψ) 网格上采样 + 前向仿真 |

网格分辨率、仿真步长、词表粒度在**本文件冻结后**写入 `src/config.py`，
**运行前不得调整**（调整即视为新预注册）。

## 4. 判据（预先写定）

| 编号 | 判据 | 通过条件 |
| --- | --- | --- |
| **P1** | E2 与 `V_analytic(τ)` 的一致性 | 相对误差 < 1e-3，在 τ ∈ {R/Va, 2R/Va, πR/Va} 三个时刻上 |
| **P2** | E1 与 `N_maneuver_analytic` 的一致性 | 完全一致（离散计数，应为精确相等） |
| **P3** | 网格收敛性 | 分辨率加倍后，E2 的相对变化 < 1e-2 |
| **P4** | w = 0 退化检查 | E2 在 w = 0 时与经典 Dubins 可达集面积一致 |
| **P5** | 单调性自检 | F 随 τ 单调不减（可达集随时间扩张） |

**总体判定**：

- **通过**：P1–P5 全部满足 → 允许进入 S1（平台搭建）；
- **部分通过**：仅 P1 或 P2 失败 → 修正估计器后重跑（本实验可重复，但每次重复必须新建修订文件）；
- **不通过**：P3 或 P5 失败 → 估计器设计有结构性问题，回到设计阶段。

## 5. 明确的"不做什么"

1. **不做任何决策比较**（不比较 A_myopic / A_penalty / A_constraint）——
   那是 S2 之后的事；
2. **不做有风场景的解析互验**（无闭式解，互验无基准）；
3. **不做功效分析**（本实验是确定性互验，无统计推断）；
4. **不涉及障碍物与围栏**（保持解析可解）；
5. **不宣称任何关于"未来可行性作为决策准则"的结论**——
   本实验只验证测量工具。

## 7. 分辨率与限制（预先声明）

- 分析解析解在 w = 0 下成立；**有风情形本实验无法验证**，是已知缺口；
- 3 自由度水平面点质量；不含高度、气动、失速；
