## 1. 决定性根因：τ 口径的掠射退化

`τ = 首个使 v(t)·n ≤ 0 的时刻` 这一口径在实现时有一个**未处理的退化情形**：

```text
v(0)·n < 0   → 飞机在 t=0 已在后退 → τ = 0，穿透 = 0
v(0)·n = 0   → **掠射**（相切）：不属于"已在后退"，应取下一个正解
```

**原实现把"掠射"误判为"已在后退"**，于是 τ 被置 0 或取错分支，穿透量严重错误。
数值影响：最大偏差 **126 m**（`notes/diagnose_27a_failures.py` 的 T1）。

**修正后的规则（模式 A，已固化于 `notes/verify_tau_fix.py`）**：

```text
若 v(0)·n < −1e-12        → τ = 0（t0_backward）
否则                       → τ = 首个满足 v·n = 0 的正时刻（解析支）
  解析支：v·n = 0 ⟺ cos(ψ0 + s·ω·τ − φ_n) = −(W·n)/Va
          令 A = arccos(−(W·n)/Va)，取 cos(θ) = ±A 的最小正 τ
```

**为何 EXP-27 未受该 bug 影响**：它取 `max over ψ0`，而最不利的 ψ0 都是"正在接近"的，
恰好绕开了掠射退化。这解释了为何 EXP-27 的数值一直是正确的。

**适用范围**：`|v(0)·n| < 1e-9` 的相切点属测度零退化，
离散暴力参照与解析式在该点必然不一致，验证时**排除**（已写入脚本）。

## 3. 仍然成立的一个物理事实（不阻塞，但有界定作用）

常值风下**盘旋轨迹是开口的**（顺风漂移），穿透量随圈数**线性增长**：

| 圈数 | 沿风向穿透（w=0.3） |
| --- | --- |
| 1 | 77.760 |
| 5 | 388.800 |
| 10 | 777.600 |

**推论**：任何有限缓冲都会被**持续盘旋**的飞机最终穿越。

**该事实的作用**（不是阻塞，而是界定）：

1. 说明 **`max_t n·d(t)` 不是良定义的量**（依赖视界）→ 因此**必须**用
   "首次外摆"（首次使 `v·n ≤ 0` 之前的最大穿透），而不是整周期最大值；
2. 给出 **K4 的界定语**：K4 说的是"**首次外摆**不越界"，**不是**"永久 contain"；
3. 说明"盘旋保证 contain"在本项目中**不成立**，不得作为验证目标。

**已固化于 `docs/FROZEN_PROTOCOL.md` 第 12.2、12.3 节。**
