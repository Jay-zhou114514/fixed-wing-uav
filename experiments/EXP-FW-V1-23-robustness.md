## 2. 主结果：精确的延迟预算法则

```text
tau_L* = 1 / ( omega · (1 + w) )            （w > 0）
```

无量纲形式：

```text
omega · tau_L* = 1 / (1 + w)                弧度
```

物理含义：延迟期间飞机尚未开始转弯，但航向已经在"损失"。
允许的**航向损失角**为 `1/(1+w)` 弧度，即约 `57.3° / (1+w)`。

- w = 0.1 → 0.909 rad ≈ 52.1°
- w = 0.3 → 0.769 rad ≈ 44.1°
- w = 0.5 → 0.667 rad ≈ 38.2°

## 3. 为什么它是精确的（三行推导）

1. 由 EXP-FW-V1-21/-22：构造在顺风方向的余量恒等于 δu = Va/ω（w > 0）。
2. 延迟期间飞机未转弯，以**顺风地速** Va(1+w) 前进。
3. 余量耗尽的条件：`Va(1+w)·τL = Va/ω` → `τL* = 1/(ω(1+w))`。

Va 在两边相消，因此结果**与空速无关**，只由最大转弯率和风速比决定。
数值实验在 3×3 网格上与解析式完全一致（偏差 0.000）。

## 4. Observation

1. 45 个参数组合全部通过全部五项判据。
2. `ω·τL*` 在每个 w 上的 9 个参数点完全重合，标准差为零。
3. 实测值与解析式 `1/(1+w)` 的相对偏差为 0。
4. 换算法的延迟预算与空速完全无关：Va 从 15 到 25 m/s，τL* 不变。

## 5. Interpretation

延迟预算是这套缓冲构造的一个**内禀属性**，由最大转弯率与风速比完全决定，
不受巡航速度影响。它的自然单位是航向角而不是秒：

> 围栏的接管延迟预算 = 1/(1+w) 弧度的转弯时间。

这也解释了为什么 δu 在顺风方向看起来"多余"：
δd 已经包含了转弯所需的那一个半径，所以再加上的 δu 实际上就是延迟预算。
**δu 同时承担两个角色：静风下的最小净空，以及有风时的延迟预算。**

## 6. Limitation

- w = 0 时方向缓冲不启用（无风向），余量为零，上式给出 1/ω 但实际为 0。
  **本法则适用于 w > 0。** 该不连续性是构造中 δd 存在非零"直流分量"
  （δd(0) = δu）的直接后果，应在论文中显式说明。
- 仍是 3 自由度水平面点质量模型；未含高度、气动、失速。
- 常值风；未含阵风、风切变、风估计误差。
- 网格仅 3×3，且假设 Va 与 ω 可独立取值；真实机型中高转弯率常伴随速度损失。
- 延迟仍被建模为"完全不转弯"。
