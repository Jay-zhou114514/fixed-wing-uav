## 0. 为什么必须先解决一个歧义

负责人要求的检验对象是"圆盘近似给出的安全边界"与"实际所需安全裕量"的比较。
但**"圆盘近似"在本项目中有两种不同读法，二者的答案可能相反**，
故必须分开定义、分开检验：

| 读法 | 定义 | 比较对象 |
| --- | --- | --- |
| **判据级（A）** | "转弯半径 R 的圆盘须完全落在围栏内" 这一**判据** | vs 飞机**实际轨迹**不越界 |
| **缓冲级（B）** | 用**各向同性**的圆盘半径 R 作为所需缓冲 | vs **方向依赖**的实际所需穿透量 |

**若混为一谈，会得到自相矛盾的报告。** 故本修订设两个独立检验。

## 1. 定义（冻结口径）

### 1.1 判据级检验（A）

同一轨迹，同一围栏（**原始**围栏 `c_e`），评价窗口同为"该边连续推进段"：

```text
轨迹：延迟 τ 直飞（地速 v_g = Va·e(ψ0) + W），随后以最大速率按 sign 转弯
      （瞬时转弯，即 τ_roll = 0；与 EXP-26 臂 I 的机动模型一致）

判据 D（圆盘）：对每条边 e 与窗口内各 t：
      d_e(c(t)) = c_e − n_e·c(t) ≥ R,     c(t) = x(t) + sign·R·perp(ψ(t))
      违反量 = max_e max_t [ R − d_e(c(t)) ]

判据 X（实际）：对每条边 e 与窗口内各 t：
      违反量 = max_e max_t [ n_e·x(t) − c_e ]

允许延迟： τ_*(判据) = max over sign of sup{ τ : 判据成立 }
判据级差值： Δ_A(x0, ψ0, w) = τ_D − τ_X
```

### 1.2 缓冲级检验（B）

```text
实际所需（方向依赖）： required_X(n)  —— 首次外摆沿方向 n 的最大穿透量
                      （由 EXP-27 的独立实现给出）
圆盘近似（各向同性）： required_C(n) = R
缓冲级差值： Δ_B(n, w) = R − required_X(n)
（Δ_B > 0：圆盘偏保守；Δ_B < 0：圆盘偏激进）
```

## 2. 假设（**方向中性，三值结论**）

对每个检验，预先规定**三种可能结论，全部可报告**：

| 结论 | 判据级（A） | 缓冲级（B） |
| --- | --- | --- |
| **一致偏保守** | 所有场景 `Δ_A ≤ 0` | 所有方向 `Δ_B ≥ 0` |
| **一致偏激进** | 所有场景 `Δ_A ≥ 0` | 所有方向 `Δ_B ≤ 0` |
| **混合** | 符号随场景变化 | 符号随方向变化 |

**本检验不预设哪一种成立**；三种均为有效结果，须如实报告各占的比例与条件。

## 3. 判据（冻结）

| 编号 | 判据 | 通过条件 |
| --- | --- | --- |
| **P1** | 判据级：给出 `Δ_A` 的**符号结构**（一致/混合）及其随 w 的变化 | 报告完整、可复现 |
| **P2** | 判据级：给出 `Δ_A` 的**量级**（`|Δ_A|` 的相对大小） | 报告完整 |
| **P3** | 缓冲级：给出 `Δ_B(n)` 的符号结构（一致/混合）及其随风向的变化 | 报告完整 |
| **P4** | 若为"一致"，须给出**等号条件**（Δ=0 成立的场景） | 报告完整 |

**判定用语纪律**：

- **不得**使用"验证了保守性"这类预设立场的表述；
- 须写为"`Δ` 的符号在 X 个场景中为 Y，占比 Z；等号出现在 ……"；
- 若出现符号翻转，**必须**如实报告并给出条件刻画。

## 5. 理论附注（**不作为判据**，仅供事后比对）

可作如下**推导**：因 `c(t) − x(t) = sign·R·perp(ψ0)`，恒有 `|x(t) − c(t)| = R`，
即飞机**始终位于其所关联的圆盘边界上**；故"圆盘在围栏内"蕴含"飞机在围栏内"。

若该推导无误，则预期 `Δ_A ≤ 0`。**但本检验的判据是经验结果**：
若实测出现 `Δ_A > 0`，则**该推导或其实现前提被证伪**，须查明原因。
**本附注不得用于预先宣布结论。**
