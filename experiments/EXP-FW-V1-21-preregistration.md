# EXP-FW-V1-21 预注册：缓冲充分性的修正判据检验

日期：2026-09-17
状态：**预注册（提交后运行）**
前置：EXP-FW-V1-20（探索性，判据已被本实验修正）

## 0. 为什么需要重做

EXP-FW-V1-20 把机动时长上限设为一个完整转弯周期 T = 2π/ω。
这等于假设飞机即使已经转向逆风，仍会继续转回顺风被风推着走。
真实接管控制器不会这样做：一旦地面速度在关注方向上的分量 ≤ 0，它就保持航向。

这个假设使 EXP-FW-V1-20 的需求量被高估，因此其"w* ≈ 0.32"的结论
**可能完全是判据artifact**，必须先排除。

## 1. 修正后的判据

对每个方向 n，定义：

```text
required(n) = max over 初始航向 psi0
              min over 转弯方向 sign
              max over t ∈ [0, tau] of  (d(t) · n)
```

其中：

- `d(t)` 为地面系位移，`v(t) = Va·e(psi(t)) + W` 为地面速度。
- `tau` 为**首个**使 `v(t)·n ≤ 0` 的时刻（即"不再朝该方向前进"）。
  到达 tau 后保持航向，航向不再变化，位移不再增加。
- 若在某转弯方向下 tau 在整个 T 内不存在，则该方向不可行，
  取 max 到 T 并标记 `infeasible`；只要另一个方向可行，取两者最小。
- **对初始航向取最坏、对转弯方向取最优**（控制器会选更有利的一侧）。
  这条在 EXP-FW-V1-20 中已被自检确认，保留。

给定缓冲（论文构造在边法线方向上的实际值）：

```text
given(n) = delta_u + delta_d · max(0, cos∠(n, phi_d))
```

## 2. 假设

| 编号 | 假设 | 判据 |
| --- | --- | --- |
| H1 | w = 0 时 required(n) 恒等于 R = δu | 最大偏差 < 1% |
| H2 | 沿风向 n = φd 时 required 恰等于论文的 δd | 相对偏差 < 1% |
| H3 | 各方向上 required(n) ≤ given(n) | 最大缺口 ≤ 0 |

H2 是本实验的核心：如果 H2 成立，说明论文第 II 节的 δd 推导
**正是**该构型下的最坏穿透量，推导是对的；那么 H3 大概率成立，
EXP-FW-V1-20 的缺口就是判据artifact，必须撤回。

## 4. 判据与判定

- H1、H2 成立且 H3 成立 → **EXP-FW-V1-20 的缺口为判据artifact，正式撤回**；
  论文构造在本文模型下充分，项目转为"确认型 + 基准"路线。
- H1 或 H2 不成立 → 实现有误，先修代码，不得推进。
- H3 不成立 → 缺口为真，进入归因实验。

无论哪种结果，按 `EXPERIMENT_STRATEGY.md` 第 5 节，**两种结果都可发表**。

## 5. 已知局限

- 仍为 3 自由度水平面点质量模型；未含高度、气动、失速。
- 常值风，未含阵风、风切变与风估计误差。
- 只测"直线边界 + 给定法向"的必要缓冲；多边形顶角带来的额外余量另由 EXP-FW-V1-22 处理。
- 单一参数点（Va=18, ω=25°/s）；参数稳健性留给后续实验。
