## 2. 主结果：安全裕度具有确定的方向结构

解析计算（w = 0.1，R = 41.2530 m，δd = 47.9394 m）：

| 方向 n | required | given | margin |
| --- | --- | --- | --- |
| 0°（沿风向） | 47.9394 | 89.1924 | **41.2530 = δu** |
| 45° | 45.9365 | 75.1512 | 29.2148 |
| 89.9° | 41.2603 | 41.3366 | 0.0763 |
| **90°（垂直风向）** | **41.2530** | 41.2530 | **0** |
| 135° | 36.7696 | 41.2530 | 4.4834 |
| 180° | 34.9736 | 41.2530 | 6.2794 |
| 270° | 41.2530 | 41.2530 | **0** |

三个风速比下的确认：

| w | margin @ 0°（沿风） | δu | margin @ 90°（⊥风） |
| --- | --- | --- | --- |
| 0.1 | 41.252961 | 41.2530 | 7.105e-15 |
| 0.3 | 41.252961 | 41.2530 | 0.000e+00 |
| 0.5 | 41.252961 | 41.2530 | 0.000e+00 |

即：

> **沿风向余量恰为 δu（= R）；垂直于风向余量恰为 0。**

EXP-FW-V1-22 只沿风向测量，因此只看到前者。

**该构造在垂直风向方向上是"精确紧"的**：
`required(90°) = R = given(90°)`。它刚好够用，没有任何冗余。

## 3. 原猜想的检验结果

`docs/LITERATURE_MAP.md` 第 11 节的猜想的**前半部分成立**：

> "当关注方向 n 落在两条边法线**之间**时，构造提供的缓冲**大于**沿法线的缓冲"

✅ 成立（P1 通过）。构造的缩放对顶点给出了额外裕度
（`h = δu/sin(θ_int/2) ≥ δu`，θ_int 越小裕度越大）。

**后半部分需要修正**：

> "因此最坏情况可能不是任意形状，而是风向与边法向一致；简单几何结构"

⚠️ **部分成立，但"矩形"不是最坏情形**。P3 的实测显示：
三个 w 下的全局最小 margin 均由**正六边形在 α = 0°**取得（方向 −90.0°），
而非对齐矩形。两者的 margin 都等于 0（差在浮点极限内），
但严格按数值，六边形是取得者。

**原因**：最坏情形由"**是否存在一条法线恰好 ⊥ 风向的边**"决定，而非由形状简单性决定。
矩形（α = 0°）与正六边形（α = 0°）都含这样的边，故都达到 margin = 0。
随机凸多边形因需同时满足"边数少"与"恰有垂直法线"，反而裕度更大（最小 0.11 m 以上）。

**修正后的表述**：

> 该构造的零裕度方向由**边法线与风向的几何关系**决定：
> 只要围栏含一条法线 ⊥ 风向的边，该方向的安全裕度即为 0（精确紧）；
> 与多边形的形状复杂度无关。

## 4. Observation（观察到什么）

1. 在 125 个构型、3 个风速比上，安全条件 `given(n_e) ≥ required(n_e)`
   在每条边法线方向全部成立；最小 margin = −4.3e-14 m（浮点零）。
2. `margin(0°) = δu` 精确成立，且**与 w 无关**（三个 w 下均为 41.252961 m）。
3. `margin(90°) = 0` 精确成立，且与 w 无关。
4. 全局最小 margin 由含"法线 ⊥ 风向"的构型取得，方向为 −90.0°。
5. 解析 `required(0°)` 与 δd 相对偏差为 0.000e+00；`required(90°)` 与 R 的
   偏差为 7.105e-15 m。
6. 首次运行（粗网格，N_PSI = 151）曾报告"最坏构型为随机多边形、
   min margin = 0.1102 m"，该结果在修订 1 中被判定为**航向网格离散化伪影**。

## 5. Interpretation（如何解释 —— 未确立）

- `margin(90°) = 0` 的结构性解释（**假说，未证明**）：
  当 `n ⊥ W` 时，飞机自初始航向沿风向转过 90° 恰好把 `d·n` 增大到 R，
  此时地速的 n 分量恰降到 0（"不再向该方向前进"）。
  构造给出的 `given(90°) = δu = R` 恰好覆盖该值。
  即 **`δu` 同时承担"静风最小净空"与"垂直风向的精确紧界"两个角色**——
  这与 EXP-FW-V1-22 发现的"δu 承担双重角色"是同一结构的两个侧面。
- `margin(0°) = δu` 且与 w 无关，与 EXP-FW-V1-22 一致，说明
  **δd 的设计恰好把沿风向的余量"锁定"为 δu**，不随风速变化。
- 若上述解释正确，则本构造的安全性是"**精确设计**"而非"保守设计"：
  它在最坏方向上零冗余。这解释了两件事：
  (a) 该构造为何在常值风下充分；
  (b) 为何**任何**未被建模的效应（延迟、风估计误差、跟踪误差）都会
      直接产生缺口——因为没有余量可消耗。

**这一推论直接指向 EXP-FW-V1-26 的必要性，但本记录不宣称它成立。**

## 6. Limitation（不能证明什么）

1. **仅凸多边形**。凹多边形与 reflex 顶点的**展平**（JAIS 第 III.B 节）
   **未实现**。该文说明展平是为**回收可用面积**（"frees flight area"），
   即会**减少**顶点处缓冲，因此凹多边形可能存在**真实缺口**。
   登记为 **EXP-FW-V1-27B**，**本实验不覆盖**。
2. **仅常值风**。δd 的定义即为 steady wind（该文原文）。
3. **仅运动学**。3-DOF 水平面点质量；不含高度、气动、失速、滚转瞬态。
4. **只检查边法线方向**。对凸多边形这是充分且必要的安全条件
   （因为可达集由方向 n 的支撑函数刻画，而约束为半平面），
   但该论证未在本文中形式化证明。
5. `required(90°) = R` 的**解析证明**仅对单个构型给出（自检 3），
   一般性的 `n ⊥ W` 证明未完成。
6. 无风估计误差、无跟踪误差、无延迟（后者属 EXP-FW-V1-26）。
