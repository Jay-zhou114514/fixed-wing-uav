## 2. 已确认的结构（可复用，属**部分完成**的净产出）

沿 C 区参数化（位置 `x0 = xv − s·b_out`，航向 `ψ0 ∥ b_out`），取
`g_e = n_e·b_out`、`q_e = n_e·perp(b_out)`、`m_e = max(0, n_e·d_wind)`：

```text
d0_e(s)  = R + δd·m_e + s·g_e − sign·R·q_e        （初始圆心到边 e 的距离）
rate_e   = Va·( g_e + w·m_e )                      （延迟段的推进速率）
```

**关键机制（本次唯一的新内容）**：转弯段中
`center(t) = c0 + w·Va·t·d_wind` —— **圆心的风致平移与转弯速率无关**。
故 `d_e(t)` 在 m_e > 0 时单调减，转弯段的消耗为

```text
dmin_turn_e = d0_e − w·Va·m_e·T_e
T_e = 首窗口末端 = [ arccos(−w·m_e) + sign·δ_e ] / ω,   δ_e = ∠(n_e, b_out)
```

**已独立验证**：`T_e` 的解析式 vs 直接扫描 rate_e 的首个正窗口，最大差 ~5e-5 s
（网格分辨率极限）；`dmin_turn_e` 的解析式 vs `_turn_segment_min_de`
在**相邻边**上一致（n=3,4 上偏差 ~1e-3 m，为 N_T=4001 网格误差）。

**显式闭式（仅相邻边绑定、`g_e = sin(θ/2)`、`q_e = ±cos(θ/2)` 时成立）**：

```text
s* = [ sign·R·cos(θ/2) − m_e·( δd − w·Va·T_e ) ] / sin(θ/2)
```

## 6. Observation / Interpretation / Limitation

### Observation

1. 转弯段圆心按 `w·Va·t` 沿风向**线性漂移**，与转弯速率无关。
2. 窗口末端 `T_e = [arccos(−w·m_e) + sign·δ_e]/ω` 与直接扫描一致（~5e-5 s）。
3. 相邻边绑定时，`d*` 有显式解；n=3 与 n=4 上偏差 ~1e-3 m（网格误差量级）。
4. w=0 时全部情形退化回 `R·cot(θ/2)`（n=3…8，最大差 2.7e-12 m）。
5. 有风时 `d*` 依赖顶点相对风向的角度 ⟹ K9 的"只由 θ 决定"在 w>0 失效。

### Interpretation

- K9 是**无风特例**；有风时它必须被"相邻边显式式 + 一般几何"替代；
- 其偏离的不规则性（n=3 大、n=6 几乎为零）来自**各边 m_e 不同**
  （即顶点相对风向的角度不同），而非 θ 本身；
- 该机制足以**定性解释** C 区表格的偏离模式，但**不足以给出通用闭式**。

### Limitation

1. 未完成项见第 3 节；**不得**当作结论使用；
2. 高分辨率核查未取得结果（被终止）；
3. 非相邻边绑定的一般情形无解；
4. 仅正 n 边形、仅常值风、仅 3-DOF。
