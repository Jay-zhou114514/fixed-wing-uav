## 0. 为什么必须做

EXP-FW-V1-27 检验的是**逐边独立**条件：

```text
对每条边 e：  given(n_e) ≥ required(n_e)
其中 required(n_e) = max_{psi0}  min_{sign}  max_t  d_sign(t; psi0)·n_e
```

注意 `min_{sign}` 的位置：**每条边各自允许选择对它最有利的转弯方向 `sign`**，
而且 `max_{psi0}` 也允许各边各自选择最不利的初始航向。

但一次真实飞行只有：

- **一个**初始航向 psi0（由接近几何决定）；
- **一个**转弯方向 sign（控制器一旦决定就要执行）。

因此闭环安全要求的是**同时**条件：

```text
对每个 psi0：  存在单一 sign，使得  ∀ e：  max_t d_sign(t; psi0)·n_e ≤ given(n_e)
```

**若不同边所需的最优 sign 不同，则逐边检查通过并不保证同时条件成立。**

这就是 EXP-27 的逻辑缺口。本条**不构成对 EXP-27 结论的反驳**——
K2/K3/K4 是对"逐边安全裕度"的陈述，该陈述本身成立；
本实验检验的是"逐边 ⇒ 同时"这一步。

## 1. 研究问题

> EXP-FW-V1-27 的逐边充分性，是否蕴含多边同时充分性？
> 若否，违反发生在什么几何条件下，量级多大？

## 2. 定义（冻结口径）

沿用 EXP-FW-V1-27 的几何与运动学口径（3-DOF 水平面点质量、常值风、
R = Va/ω、δu = R、δd 按 JAIS 2020），仅把约束组织方式改变：

```text
给定：多边形 P（半平面 n_e·x ≤ c_e）、风速比 w、初始航向 psi0、转弯方向 sign ∈ {+1,−1}

R_e(sign; psi0) = max_{t ≤ τ_e}  d_sign(t; psi0)·n_e
        其中 τ_e 为首个使 v(t)·n_e ≤ 0 的时刻（沿用 EXP-21/27 口径）

given_e = c_e − h_{P_s}(n_e)          构造提供的缓冲（缩放层支承函数）
         其中缩放层由 c'_e = c_e − δu − δd·max(0, n_e·d_wind) 生成

违逆量 violation(sign; psi0) = max_e [ R_e(sign; psi0) − given_e ]
可行      feasible(psi0) = min_{sign} violation(sign; psi0) ≤ 0
同时违逆  V(psi0)        = min_{sign} violation(sign; psi0)     （>0 即违反）
```

**同时充分** ⟺ 对所有 psi0：`V(psi0) ≤ 0`。

## 3. 待检验命题

| 编号 | 命题 | 性质 |
| --- | --- | --- |
| **H-A** | 对凸多边形与常值风，同时条件成立（`max_psi0 V(psi0) ≤ 0`） | 与 EXP-27 结论一致 |
| **H-B** | 同时条件在**顶点附近**可能被违反（`max_psi0 V > 0`） | 与 EXP-27 结论冲突，需修正 |

**两者都可发表**：H-A 成立则 EXP-27 的几何基准可靠；
H-B 成立则是一个**更强的发现**（该构造在凸多边形上也不充分）。

## 4. 参数

| 项 | 取值 |
| --- | --- |
| Va / ω | 18 m/s / 25 °/s（R = 41.2530 m），其余为空速无关性对照 |
| w | {0.0, 0.1, 0.3, 0.5} |
| 多边形 | 矩形（长宽比 1, 2, 3）× 朝向 {0°, 5°, …, 45°}；正 n 边形 n = 3…8 |
| 尺度 | 统一归一化到相同外接半径（沿用 EXP-27 的口径） |
| psi0 网格 | 均匀 8001 点 **+ 显式加入"指向各顶点"的航向**（关键构型，不得遗漏） |
| sign | {+1, −1} 两者都算（不再取 min 作为逐边值，而是分别保留） |

**注意**：psi0 必须**显式包含指向各顶点的航向**——顶点是 H-B 可能发生之处，
不能只靠均匀网格（EXP-27 的教训：网格漏掉临界构型会造成伪影）。

## 5. 判据（预先写定）

| 编号 | 判据 | 通过/判定条件 |
| --- | --- | --- |
| **P1 自检** | 单条直线边界（退化为无顶点）时，同时对每条边均可行 | 违反数 = 0 |
| **P2 复现** | w = 0 的对齐矩形：逐边检查的 margin = 0（与 EXP-27/22 一致） | 绝对偏差 < 1e-6 m |
| **P3 收敛性** | `V` 的最大值在 psi0 网格加密下稳定 | 加密一档后变化 < 1e-7 m |
| **P4 判据** | 报告 `max_psi0 V`：≤ 0 则 H-A 成立，> 1e-9 则 H-B 成立 | 二选一，必须明确 |
| **P5 几何定位** | 若 H-B 成立，报告违反发生的方向范围与顶点角的关系 | 描述性 |

**阈值说明**：P4 的 1e-9 m 用于区分"精确为零（浮点零）"与"真实正违反"。
若 `max V` 落在 (0, 1e-9) 区间，视为浮点零，按 H-A 处理，并在记录中说明。

## 6. 明确的"不做什么"

1. **不引入新物理**：无控制延迟、无滚转动力学、无跟踪误差（那些属 EXP-26）；
2. **不覆盖凹多边形与顶点展平**（属 EXP-FW-V1-27B）；
3. **不做风估计误差**（属 EXP-FW-V1-28）；
4. **不宣称任何新颖性**；
5. 不重复 EXP-27 的逐边结论——本实验只回答"逐边 ⇒ 同时"这一步。
