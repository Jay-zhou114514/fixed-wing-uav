# EXP-FW-V1-02 预注册：地面转弯半径各向异性定律

日期：2026-09-16
状态：解析推导完成，一次性数值互验通过，但可复现脚本/CSV/图尚未落库（部分完成）

## 研究问题

固定翼以恒定滚转角转弯时，它在**地面坐标系**里画出的圆弧半径是多少？
这个半径是否与航向相对于风向的夹角有关？

## 假设

H1（解析）：定常空速 Va、定常滚转 φ 的协调转弯，航向角速度 ψ̇ = g·tanφ / Va，
地面航迹曲率满足

```
κ_g = Va · ψ̇ · (Va + W·e_ψ) / |Va·e_ψ + W|³
```

由此，地面转弯半径与空气系半径之比为

```
R_g / R_a = (1 + 2w·cosθ + w²)^{3/2} / (1 + w·cosθ)
```

其中 w = |W| / Va，θ 为航向与风向的夹角，R_a = Va² / (g·tanφ)。

H2（数值）：对以上运动学方程做数值积分并用有限差分估计曲率，结果与 H1 的解析式
在所有 w 与 θ 上一致（最大相对误差 < 1e-3）。

H3（量级）：w = 0.3 时，顺风地面半径与逆风地面半径之比超过 3。

## 指标定义

- 解析曲率 κ_analytic：上式。
- 数值曲率 κ_numeric：对地面航迹 (x(t), y(t)) 用中心差分求一阶二阶导，
  κ = |x'y'' − y'x''| / (x'² + y'²)^{3/2}。
- 相对误差：|κ_numeric − κ_analytic| / |κ_analytic|。
- 各向异性比：在 w 固定时 max(R_g)/min(R_g) 对 θ 遍历。

## 场景

- 空速 Va = 18 m/s，最大滚转 35°，滚转取满舵。
- w ∈ {0, 0.05, 0.1, 0.15, 0.2, 0.25, 0.3, 0.35, 0.4, 0.45, 0.5}
- θ ∈ {0°, 30°, 60°, ..., 330°}
- 积分步长 dt = 0.002 s，转弯 3 整圈。

## 判据

- H1、H2 成立 → 该定律可作为后续所有规划的几何基础，证据等级 A。
- H3 成立 → "常数半径假设"存在量级级别的风险，值得立项。
- H2 失败 → 检查积分器或差分格式，不进入 EXP-FW-V1-03。

## 判定规则

数值验证只能确认"运动学实现对"，不能确认"真实飞机如此"。
后者需要 6 自由度模型或飞行数据，标为已知局限，不计入本实验结论。
