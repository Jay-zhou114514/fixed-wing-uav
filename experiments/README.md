## 状态取值

`未开始` / `预注册完成，未运行` / `运行中` / `已完成` / `已否决` / `已作废`

## 规则

1. 预注册文件必须在产生任何结果前写好并提交。
2. 阈值、参数、判据只能来自训练/验证场景，测试场景只在最后打开一次。
3. 用测试场景做过的任何选择，必须标注为 *post-hoc*。
4. 失败的实验保留，不删除。
5. **场景族是区组，不是独立样本。** 同族场景共享生成器参数，不得当作独立重复。
6. **每个进入结论的数字必须可追溯到「编号 + 脚本 + 日志 + CSV」。** 解析数字须标"解析"并做数值互验。
