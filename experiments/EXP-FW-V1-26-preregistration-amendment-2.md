## 0. 为什么需要本修订（方法偏离的自我更正）

C 区扫描（`EXP-FW-V1-26-critical-distance.md`）存在**两项方法偏离**：

1. **无预注册**：P7 的判据文本已在预注册中，但**参数化方式**与**预言 `d* = R`**
   是写脚本时才确定的，未先提交修订文件；
2. **辨识与确认同源（更严重）**：实际时序为
   「先跑预览 → **看到** `d*/R` 数值 → 才导出公式 `cot(θ/2)` → 再确认」。
   且确认使用的 θ（`n = 3,4,5,6`）**就是辨识用的同一组**。
   **故"P7 成立且给出闭式"的表述偏强**：该公式属**事后识别**，
   尚未在独立样本上接受预测检验。

**本修订的目的**：以**全新样本**对公式做真正的预测检验。

## 1. 待检验的预测（冻结）

> **预测**：在无风（w = 0）时，凸多边形任一顶点的临界距离为
>
> ```text
> d* = R · cot(θ/2)
> ```
>
> 其中 θ 为该顶点内角，R = Va/ω。**该式声称 d* 只由 θ 与 R 决定**，
> 与多边形的其他几何（边长、其他顶点角度、整体形状）无关。

## 2. 独立样本（**不得使用 n = 3,4,5,6**）

| 测试 | 样本 | 与辨识样本的关系 |
| --- | --- | --- |
| **T-A 新 θ（规则多边形）** | n = 7, 8, 9, 10, 12, 16 | **全新 θ**（128.6°, 135°, 140°, 144°, 150°, 157.5°） |
| **T-B 不规则多边形（楔形三角）** | 顶点角 θ ∈ {70°, 90°, 110°, 130°}，两射线长 L = 20R | **形状全新**；用于检验"θ 充分性" |

**T-B 的设计要点**：楔形三角的顶点角可精确指定，其余两角随 L 而变。
若 `d*` 确实只依赖 θ，则不同 L（其他角度变化）应给出同一 `d*/R`。

**附加检查**：在 T-B 中对同一 θ 取 L ∈ {10R, 20R, 40R}，
验证 `d*` 对 L 不敏感（即**对其他几何不敏感**）。

## 3. 判据（冻结）

| 编号 | 判据 | 通过条件 |
| --- | --- | --- |
| **P1** | T-A：`d*/R = cot(θ/2)`（w=0） | 全部偏差 < 1e-6 |
| **P2** | T-B：楔形顶点同样满足 | 全部偏差 < 1e-6 |
| **P3** | T-B：`d*` 对 L 不敏感 | 跨 L 极差 < 1e-6 |
| **P4**（三件套） | 负对照 / 正对照 / 交叉验证 | 见第 4 节 |

**证伪条件**：任一判据失败 ⇒ 公式**不成立或需限定**，原表述必须降级。

## 4. 三件套（先跑，不得颠倒）

| 项 | 内容 | 期望 |
| --- | --- | --- |
| (a) 负对照 | 深内部（距各边 ≥ 2R）τ=0 无越界 | 无越界 |
| (b) 正对照 | d=0 处 `τ_crit < 0`，且扫描找到符号变化 | 找到 `d*` |
| (c) 交叉验证 | 解析 vs 数值二分（τ ≥ 0 区间） | 差 < 1e-3 |

**任一不过 ⇒ 不讨论 P1–P3。**

## 5. 规则

3. 若 P1/P2 失败，**不得**为保住公式而调整样本或放宽阈值；
4. 失败与偏离记录保留。
