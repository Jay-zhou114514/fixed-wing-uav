- 状态：**修订文件，不覆盖原预注册**（按 `docs/CONVENTIONS.md` 第 13 节）
- 原预注册：`experiments/EXP-FW-V1-27-preregistration.md`（判据 P1–P5 保持不变）

## 0. 为什么要修订

首次运行（v1，粗网格）报告了两个结果，**均为数值伪影**：

1. 报告"最坏构型为随机多边形 rand10 在 90.5° 方向，min margin = 0.1102 m"；
2. 报告 P3 不通过（并非对齐矩形最差）。

**根因**：`required(n)` 由**暴力网格**计算：
- 时间网格 N_T = 1500（覆盖一个转弯周期）；
- 航向网格 N_PSI = 151；
- 方向网格 721 点（步长 0.499°）。

其中**航向网格**是致命缺陷。收敛性检验（下表）显示：

| N_PSI | required(90°) | R − required |
| --- | --- | --- |
| 2 001 | 41.220577 | 3.238e-02 |
| 4 001 | 41.236765 | 1.620e-02 |
| 8 001 | 41.244862 | 8.099e-03 |
| 20 001 | 41.249721 | 3.240e-03 |
| 50 001 | 41.251665 | 1.296e-03 |
| 200 001 | 41.252637 | 3.240e-04 |

误差逐次**减半**（O(1/N)），收敛到 0。即 `required(90°) = R` **精确成立**。
而 N_PSI = 151 时误差达 0.03 m——**与被测裕度同阶**，因此 v1 报出的
"90.5° 尖峰（+0.3 m）"和"min margin = 0.11 m"都是伪影。

**时间网格**检验为**收敛**（N_T = 1500/6000/24000 数值稳定到小数点后 4 位），
不是问题来源。

## 1. 方法修正：解析求解 τ

关键观察：

```text
d/dt (d(t)·n) = v(t)·n
```

在首个使 `v·n ≤ 0` 的时刻 `τ` 之前，`v·n > 0`，故 `d(t)·n` **严格单调递增**，
因此 `max_{t ≤ τ} d(t)·n = d(τ)·n`——**不需要时间网格**。

而 `τ` 可解析求出：`v·n = Va·cos(ψ(t) − φ_n) + W·n = 0`
⟹ `cos(θ) = −(W·n)/Va`，其中 `θ = ψ0 + s·ωt − φ_n`。
令 `A = arccos(−(W·n)/Va)`，则角度增量 `τ_ang` 由 `θ ∈ {A, −A} (mod 2π)` 的最小正解给出，
时间为 `τ = τ_ang/ω`。

**修正后的实现**：仅对 ψ0 取网格（可用很细，如 N_PSI = 20001），τ 解析求得。
速度提升数量级，精度提升数量级。

**验证**：修正后 `required(0°) = 47.939398 = δd`（w = 0.1），
与原预注册所依赖的 EXP-FW-V1-21 的 H2 结果**精确一致**。

## 2. 同时修正的安全条件方向集

原判据隐含在"所有方向"上检查。但多边形由半平面 `n_e·x ≤ c_e` 定义，
安全条件为**对每条边**：`max_{可达} d·n_e ≤ c'_e`。

即**只需在边的外法线方向检查**，不需要也不应该在方向网格上采样
（网格会漏掉恰好落在格点之间的边法线，v1 的 0.499° 步长即漏掉 90.5°）。

修正后：边法线**精确取值**。

## 3. 判据的变化

**判据 P1–P5 保持不变**（原预注册冻结），但 P2/P3 的报告口径需明确：

- **P2**（充分性）：`min margin ≥ 0`。修订后预期在**等式处**成立（见下），
  因此报告为"min margin = 0（精确紧）"而非"严格为正"。
- **P3**（最坏情形 = 对齐矩形）：原判据为
  "全局 min margin 与对齐矩形 min margin 之差 < 1e-6"。
  修订后若两者**均为 0**，则该判据在数值上**恒成立**（0 − 0 = 0），
  失去区分度。**因此 P3 增加一条限定**：
  除比较数值外，还须报告取得最小值的**方向**是否为该多边形的边法线 ⊥ 风向。
- **新增 P6**（本次修订引入，作为**探索性附加判据**，不计入原 P1–P5）：
  `margin(n)` 在 `n ∥ 风向` 时等于 δu，在 `n ⊥ 风向` 时等于 0。

## 4. 由修订发现的一个新结果（登记为候选，等级 C）

解析计算给出（w = 0.1，R = 41.2530，δd = 47.9394）：

| 方向 n | required | given | margin |
| --- | --- | --- | --- |
| 0°（沿风向） | 47.9394 | 89.1924 | **41.2530 = δu** |
| 45° | 45.9365 | 75.1512 | 29.2148 |
| 89.9° | 41.2603 | 41.3366 | 0.0763 |
| **90°（垂直风向）** | **41.2530** | 41.2530 | **0.0000** |
| 135° | 36.7696 | 41.2530 | 4.4834 |
| 180° | 34.9736 | 41.2530 | 6.2794 |
| 270° | 41.2530 | 41.2530 | **0.0000** |

即：

> **沿风向余量 = δu（EXP-FW-V1-22 已测），垂直于风向余量 = 0（本次解析发现）。**

EXP-FW-V1-22 只在沿风向测量，故未观察到该结构性差异。

**候选推论（等级 C，未验证）**：延迟预算具有方向依赖性
`τL*(n) = margin(n) / (v·n)`，在 `n ⊥ W` 处为 **0**，
在 `n ∥ W` 处退化为 EXP-FW-V1-23 的 `1/(ω(1+w))`。
**该推论不得写入任何结论**，需 EXP-FW-V1-26（闭环）验证。
