## 1. 冻结的预测

> w = 0 时 `d* = R·cot(θ/2)`，且 **`d*` 只由 θ 与 R 决定**——
> 与边长、其他顶点角度、整体形状**无关**。

## 2. 独立样本（**未使用 n = 3,4,5,6**）

| 测试 | 样本 | 独立性 |
| --- | --- | --- |
| **T-A** | 规则多边形 n = 7, 8, 9, 10, 12, 16（θ = 128.6°…157.5°） | **全新 θ** |
| **T-B** | 楔形三角，顶点角 θ ∈ {70°, 90°, 110°, 130°}，射线长 L ∈ {10R, 20R, 40R} | **全新形状**；检验"θ 充分性" |

**T-B 的设计要点**：楔形三角只有顶点角受控，其余两角随 L 变化。
若公式只依赖 θ，则同 θ 不同 L 应给出**同一** `d*/R`。

## 6. Observation / Interpretation / Limitation

### Observation

1. P1（6 个新 θ）：与 `cot(θ/2)` 最大偏差 6.11e-16。
2. P2（4 个楔形 θ）：最大偏差 6.66e-16。
3. P3：同一 θ 下 L 从 10R 变到 40R，`d*/R` **完全不变**（极差 0）。
4. 三件套全过（负对照 0 越界；正对照 10/10 找到符号变化；交叉 6.04e-11）。

### Interpretation

- 闭式**在独立样本上成立**，且**形状无关性**得到直接支持；
- 物理含义：顶点死区沿分角线的延伸 `R·cot(θ/2)` **由内角唯一决定**，
  与其他几何无关——这是一条**局部几何定律**；
- 工程含义：围栏设计中，各顶点的死区可由内角**逐个算出**，无需整体可达性分析。

### Limitation

1. 仅 **w = 0**（有风情形的闭式仍未推导）；
2. 参数化限于沿**向内分角线**；
3. 楔形三角的射线长有限（L ≤ 40R），未严格取极限；
4. 仅凸多边形、常值风、3-DOF、一阶外摆视界；
5. **本次仅验证"是否成立"，未涉文献新颖性判定**（文献核查见下节）。
