## 0. 预注册前的良定义性探索结果（FROZEN_PROTOCOL 12.2 要求）

在写本预注册之前，先做了视界良定义性检验（`notes/exp26_horizon_wellposedness.py`）。
**该检验改变了本实验的场景设计**：

| 检验 | 结果 |
| --- | --- |
| 单边：`τ_crit` 解析式 vs 逐点数值 | 差 **0.00e+00**；确认 `τ_crit = margin(n)/(v_g·n)` |
| 沿风向退化 | `τ_crit = 1/(ω(1+w)) = 1.76295 s`（= EXP-23 的 τL\*）✓ |
| **顶点：盘拟合（联合条件）** | **`τ_crit` 为负**：矩形顶点（θ=90°）处 `τ_crit = −2.2918 s` |
| 该负值的量级 | 越界量 = **29.170 m = R·cos(45°)**，与 **K8 完全吻合** |

**关键含义**：

> **顶点区域不存在正的"允许延迟"** —— 飞机在缩放层顶点上、
> 朝顶点外方向时，**即使延迟为零，转弯圆盘已经越界 `R·cos(θ/2)`**。
>
> 因此"允许延迟预算"这一概念**只在离顶点足够远的边上有正解**；
> 顶点邻域本身已属"不可行"（与 27A 的 H-B 一致）。

**该发现直接决定本实验的场景设计**（见第 3 节）：必须**区分**两类位置。

## 1. 研究问题

> 在**联合条件**（转弯圆盘对全部边同时可行）下，
> 允许的接管延迟 `τ_crit` 如何随**接近方向**、**风速比**与**位置（离顶点的距离）**变化？
> 它是否等于 `margin_joint/(v_g·n)`，且在真实滚转动力学下减少一个滚转时间常数？

## 2. 定义（冻结口径）

沿用 27A 的几何与 27 的构造；**新增延迟**。

```text
构造：给定多边形 P，缩放层由 c'_e = c_e − δu − δd·max(0, n_e·d_wind) 生成（JAIS 2020 第 III.B 节）
位置：x0（候选位置见第 3 节）
初始航向：ψ0（由"接近几何"决定，见第 4.2 节的防同义反复条件）
机动：先直飞 τ（延迟），再以最大速率按 sign 转弯；围栏跟随控制器在其后接管

联合条件（V2.2 决定 4）：对**所有**边 e 同时成立
    d_e(τ) = c_e − n_e·c(τ) ≥ R,    c(τ) = x0 + v_g·τ + sign·R·(−sinψ0, cosψ0)
因 c(τ) 对 τ 线性：
    τ_crit(sign; x0,ψ0) = min over {e : n_e·v_g > 0} of  [d_e(0) − R]/(n_e·v_g)
    τ_crit(x0,ψ0)       = max over sign of τ_crit(sign; ...)
```

**注**：`d_e(0) − R < 0` 表示**τ=0 即已越界**（顶点邻域），此时 `τ_crit < 0`。

## 3. 场景设计（**因第 0 节发现而修订**）

**三区设计**（替代 V2.1 未规定的场景）：

| 区 | 位置 x0 | 预期 | 作用 |
| --- | --- | --- | --- |
| **A 区（单边）** | 距单条边 `given(n)` 处的边中点 | `τ_crit = margin(n)/(v_g·n) > 0` | 检验 H1（正延迟） |
| **B 区（近顶点）** | 缩放层顶点 | `τ_crit < 0`（τ=0 已越界） | 检验 K8 的任务层对应物 |
| **C 区（过渡）** | 从顶点沿边向内移动 | `τ_crit` 由负转正 | 定位**临界距离** |

**A 区**是 H1/H2/H3 的主检验场；**B/C 区**是 27A 结论的任务层确认。

## 4. 设计

### 4.1 自变量

| 变量 | 取值 |
| --- | --- |
| 接近方向 φ（相对风向） | 0°, 30°, 45°, 60°, 90°, 120°, 135°, 180°（含对称侧） |
| 接管延迟 τ | 0 … 1.5 τL\*，步长 0.05 s（临界区加密） |
| 风速比 w | 0.0, 0.1, 0.3, 0.5 |
| 空速 Va | 15, 18, 25 m/s（检验 H2） |
| τ_roll（仅臂 R） | 0.3, 0.5, 0.8 s |
| 离顶点距离（C 区） | 0, 0.25R, 0.5R, 1R, 2R, 4R |

### 4.2 防同义反复（`EXP-26` 的硬条件，沿用 V2.1 第 4.6 节）

**三条缺一则重做**：

1. **臂 I 必须独立实现**——不得调用 EXP-27 的 `required()` 或 27A 的 `pen_vec()`；
   只允许运动学积分 + 围栏几何。
2. **触发由接近几何决定初始航向**——EXP-27/27A 对 ψ0 取**对抗性最优**；
   本实验的 ψ0 由"飞机朝向目的地的航向"决定。两者只有在轨迹确实抵达警告层时才一致。
3. **H3 是本实验真正的新内容**——一阶滚转动力学的修正量 `τ_roll`
   **不来自**任何已有几何计算。

### 4.3 双臂

| 臂 | 滚转 | 预言 |
| --- | --- | --- |
| **臂 I（理想）** | 瞬时 | `τ_crit = margin_joint/(v_g·n)`（H1） |
| **臂 R（真实）** | 一阶响应，`τ_roll` | `τ_crit = τL* − τ_roll`（H3） |

### 4.4 因变量

1. 是否越界（二值，穿越原始围栏 `c_e`）；
2. 越界深度（m）；
3. 实测临界延迟 `τ_crit^meas`（二分细化）。

## 5. 判据（沿用 V2.1 P1–P6；P1 与 P5 按 V2.2 修订）

| 编号 | 判据 | 通过条件 |
| --- | --- | --- |
| **P1（修订）** | 臂 I 的 `τ_crit^meas` 与**联合条件**解析式一致；**A 区**（边中点）应无越界（负对照） | 相对偏差 < 1e-3 |
| **P1b（新增）** | **正对照**：B 区（顶点）**必须**报出 `τ_crit < 0` 或 τ=0 即越界 | 越界发生 |
| **P2** | A 区 φ=90°（n ⊥ W）时 `τ_crit = 0` | 绝对偏差 < 1e-6 s |
| **P3** | A 区 `τ_crit` **与 Va 无关**（H2） | 跨 Va 变异系数 < 1e-3 |
| **P4** | 臂 R：`τ_crit = τL* − τ_roll`（H3） | 相对偏差 < 5% |
| **P5（修订）** | B 区：**即使 τ=0 也越界**，且越界量 ≈ `R·cos(θ/2)`（K8 的任务层确认） | 相对偏差 < 5% |
| **P6** | 失效侧越界深度随 τ − τ_crit 线性增长 | 线性拟合 R² > 0.99 |
| **P7（新增，C 区）** | 存在临界距离 `d*`，使 `τ_crit(d) < 0` 当且仅当 `d < d*` | `d*` 可复现（跨 w、跨多边形） |

**判定**：

| 结果 | 含义 | 行动 |
| --- | --- | --- |
| P1–P7 全通过 | 支持 H1+H2+H3 + K8 有任务层对应物 | 项目为**发现型** |
| P1–P3 通过、P4 失败 | H3 假 | 退回"理想模型下的方向结构"（边界型） |
| P2 或 P3 失败 | 方向结构无任务层对应物 | 降级为"优秀大创 + 负结果" |
