| w | 风速 (m/s) | δu (m) | δd (m) | given (m) | 沿风向需求 (m) | **τL\* (s)** | 粗估 δu/[Va(1+w)] |

| 0.1 | 1.8 | 41.25 | 47.94 | 89.19 | 47.94 | **2.1** | 2.08 |
| 0.2 | 3.6 | 41.25 | 55.04 | 96.29 | 55.04 | **2.0** | 1.91 |
| 0.3 | 5.4 | 41.25 | 62.56 | 103.82 | 62.56 | **1.8** | 1.76 |

| 0.5 | 9.0 | 41.25 | 78.93 | 120.18 | 78.93 | **1.6** | 1.53 |

**在 w = 0.1–0.5 区间，临界接管延迟 τL\* ≈ 1.6–2.1 秒，且随风速增大而略减。**

设计规则（H4，偏差 ≤ 5%）：

```text
允许延迟  ≈  δu / (Va · (1 + w))     =  转弯半径 / 顺风地速
```

## 3. 结构发现：余量恒为一个转弯半径（w > 0），静风下为零

沿风向方向：

```text
given   = δu + δd(w)
required = δd(w)
margin   = δu = R         （对一切 w > 0 成立）
```

也就是说，**余量与风速无关，恒等于一个转弯半径**。原因在于 δd 在 w = 0 时并不为零：

```text
δd(0) = R · sqrt(1) + 0 · arccos(0) = R = δu
```

即 δd 本身已经包含了"转弯所必需的那一个半径"，而 δu 又把它加了一遍。
两个量并非彼此独立。

**因此有一个反直觉的结论**：静风（w = 0，δd = 0）时
`given = δu = R`、`required = R`，**余量恰好为零**。
δu = Va/ω 在静风下正是精确的最小缓冲距离：飞机在距边界 R 处正对边界飞来、
立即以最大转弯率转向，其航迹恰好与边界相切。
所以哪怕 0.1 秒的延迟也会造成越界（τL* 落在扫描网格的第一步，属该极端情形的直接后果）。

**含义**：这个构造在静风下没有余量，在有风时余量恒为一个转弯半径。
换句话说，安全性并不随"风更大"而改善或恶化，余量是常数。

## 4. Observation

1. τL = 0 时沿风向的最坏穿透量精确等于 δd（偏差 0）。
2. 最坏穿透量随延迟单调增加。
3. 临界延迟 τL* 随 w 从 2.1 s 降到 1.6 s。
4. τL* 与 `δu/(Va(1+w))` 在 w ≥ 0.1 时吻合到 5% 以内。
5. 沿风向余量恒为 δu（w > 0）；w = 0 时余量为 0。

## 5. Interpretation

论文给出的缓冲预算是两个量相加，但这两个量在"转弯"这一项上重叠，
因此构造在顺风方向上有恒定的一个转弯半径的余量，而不是零余量。

**这不是缺陷，而是一条可用的设计规则**：该构造隐含了一个延迟预算，
其大小恰好是一个转弯半径所对应的飞行时间。对典型小型固定翼
（Va = 18 m/s、ω = 25°/s），这个预算是 **1.6–2.1 秒**。

由此可以给出一条实践判据：

- 机载自驾仪实现（延迟约 0.1–0.5 s）：预算充裕，构造可用。
- 地面站或人在环实现（延迟常达数秒）：预算可能被耗尽，需额外放大缓冲。

## 6. Limitation

- 延迟被建模为"完全不转弯"，未含部分转弯、驾驶员介入或舵面滞后。
- 仍为 3 自由度水平面点质量模型；未含高度、气动、失速。
- 常值风；未含阵风、风切变、风估计误差。
- 单一参数点（Va = 18 m/s，ω = 25°/s）。H4 的比例关系需要在参数网格上确认。
- 只算直线边界的必要缓冲；多边形顶角的额外余量未计入（只会更保守）。
- w = 0 的零余量结论应理解为"δd = 0 这一配置的精确最小性"，
  不应表述为"该构造不安全"。
