# EXP-FW-V1-27 预注册：一般多边形围栏的缓冲充分性

- 日期：2026-09-17
- 状态：**在运行实验之前冻结**（本文件先于任何 EXP-FW-V1-27 结果提交）
- 依据：`RESEARCH_PLAN_v2.0.md` 方向 B；`docs/LITERATURE_MAP.md` 第 11 节的**可检验预言**
- 前置：EXP-FW-V1-21（矩形情形，已完成）

## 0. 为什么做这个

EXP-FW-V1-21 在"围栏存在一条外法线沿风向的边"（矩形即属此类）的构型下，
验证了缓冲构造无缺口，沿风向余量恒为 δu。

但 JAIS 2020 的方法是对**任意多边形**定义的。
`docs/LITERATURE_MAP.md` 第 11 节已推导出一个**待检验的预言**：

> 当关注方向 n 落在两条边法线**之间**时，构造提供的缓冲**大于**
> 沿法线的缓冲；因此矩形（法线沿风向）可能是**最坏情形**。

本实验就是去检验这个预言。它决定"该构造是否对一般几何成立"。

## 1. 科学问题

> JAIS 2020 的 δu ⊕ δd 缓冲构造，在**一般凸多边形**上是否仍然充分？
> 若充分，其安全裕度的**最小值**由什么几何构型取得？

## 2. 定义（本实验冻结的口径）

```text
h_P(n)           原多边形在方向 n 上的支撑函数 = max_{x∈P} x·n
h_{P_s}(n)       缩放后多边形在方向 n 上的支撑函数
given(n) = h_P(n) − h_{P_s}(n)     构造在方向 n 提供的缓冲
required(n)                        飞机在方向 n 的"不可避免穿透量"（EXP-21 口径）
margin(n) = given(n) − required(n) 安全裕度
δu = Va/ω = R                      均匀缓冲
δd = R√(1−w²) + w·R·arccos(−w)     方向缓冲（w > 0）
```

**构造实现**（对应 JAIS 第 III.B 节的顶点位移，对凸多边形等价于支承线内移）：

```text
c'_e = c_e − δu − δd·max(0, n_e · d_wind)      对每条边 e
```

其中 `n_e·x ≤ c_e` 是原多边形的半平面表示。
由 Eq.(16) 的顶点位移 `h = δu/sin(θ/2)` 可导出上述等价形式（见脚本自检）。

## 3. 待检验命题

| 编号 | 命题 | 性质 |
| --- | --- | --- |
| **H1 下界性** | 对任意凸多边形、任意方向 n：`given(n) ≥ δu + δd·max(0, cos∠(n, φd))` | 主命题 |
| **H2 最坏情形** | 全部测试多边形中，`min_n margin(n)` 的**最小值**由"边法线与风向对齐的矩形"取得 | `LITERATURE_MAP` §11 的预言 |
| **H3 否证目标** | 存在多边形使 `min_n margin(n) < 0`（即原构造存在隐藏适用条件） | 用于否证 |

| 项 | 取值 |

## 5. 判据（预先写定）

| 编号 | 判据 | 通过条件 |
| --- | --- | --- |
| **P1** | H1 的下界在全部 (多边形, w, n) 上成立 | 违反数 = 0 |
| **P2** | 全部构型的 `min_n margin(n) ≥ 0`（充分性） | 违反数 = 0 |
| **P3** | `min_n margin(n)` 的最小值出现在对齐矩形 | 见下 |
| **P4** | **自检**：w = 0 时对齐矩形的 `min_n margin = 0`（与 EXP-22 一致） | 绝对偏差 < 0.01 m |
| **P5** | 顶点的额外裕度随顶角 θ 减小而增大（H1 的等号条件） | 单调性成立 |

**P3 的精确表述**：记各构型的 `m_min`。判据为
`min(全体 m_min)` 与"对齐矩形（α=0）的 m_min"之差 < 1e-6 m。

## 6. 明确的"不做什么"（局限预先声明）

1. **不处理凹多边形与 reflex 顶点**。JAIS 第 III.B 节对
   "缩放方向上角 > π 的顶点"做**展平**（flattening），
   并明确说明展平是为了**回收可用面积**（"The flattening of vertices frees flight area"）。
   展平会**减少**顶点处的缓冲，因此凹多边形存在**真实的潜在缺口**，
   但忠实实现展平需要该文第 III.B 节后半段与本项目重建的交叉验证，
   本实验**不覆盖**，登记为 **EXP-FW-V1-27B**（凹多边形与展平）。
2. 不做风估计误差（属后续阶段）；
3. 不做跟踪误差（属后续阶段）；
4. 不涉及平滑（smoothing）——该文已声明平滑是保守的（"biased toward further
   restricting the reachable flight volume"），故不影响充分性方向。
5. **不宣称任何新颖性**。
