# EXP-FW-V1-27A 预注册修订 1：飞机位置的精确规定

- 日期：2026-09-17
- 状态：**修订文件，不覆盖原预注册**（按 `docs/CONVENTIONS.md` 第 13 节）
- 原预注册：`experiments/EXP-FW-V1-27A-preregistration.md`（判据 P1–P5 不变）
- 触发：准备脚本时发现原预注册**未规定飞机位置**，而这对多边同时条件不唯一

## 0. 为什么必须补这一条

EXP-21/27 的逐边条件具有**平移不变性**：
`required(n) ≤ given(n)` 只涉及沿方向 n 的位移与缓冲，与飞机在别处的位置无关。

但**多边同时条件不具备平移不变性**。约束是"到每条边的距离"，写成半平面即

```text
对每条边 e：  R_e(sign; psi0) ≤ c_e − n_e·x0
```

其中 `x0` 是**飞机的实际位置**。该式明显依赖 x0。

因此"同时条件是否成立"取决于飞机位于何处。原预注册只写了
`given_e = c_e − h_{P_s}(n_e)`（逐边口径），等价于隐含假设飞机同时位于
所有边的"恰好 given_e 距离"处——这在几何上一般**不可能**。
该假设在多边情形下必须显式替代。

## 1. 修订：飞机位置的冻结规定

**主分析位置**（最坏情形候选）：

> 飞机位于**缩放层（警告层）的顶点**上。即 x0 ∈ verts(P_s)。

**理由**：缩放层顶点是两个（或多个）约束同时紧的位置。在多边形内部，
若飞机不在缩放层顶点上，则至少有一条边的距离严格大于其 `given_e`，
约束更宽松。因此缩放层顶点是同时条件最容易失败的位置。

**补充采样**（用于完备性，非主分析）：

> 在缩放层每条边上按等参数采样 100 点。

两处都检查，分别报告。若二者结论不同，以**主分析（顶点）**为准，
并在记录中说明差异。

## 2. 修订后的判定式

对每个 x0（主分析：缩放层顶点）与每个 psi0：

```text
room_e(x0)      = c_e − n_e·x0                  到边 e 的可用距离
viol(sign; x0, psi0) = max_e [ R_e(sign; psi0) − room_e(x0) ]
V(x0, psi0)     = min_{sign} viol(sign; x0, psi0)
```

**同时充分** ⟺ 对所有 (x0, psi0)：`V ≤ 0`。

报告量：

- `maxV = max over x0, psi0 of V`（H-A/H-B 的判定量）；
- 取得 maxV 的 (x0, psi0) 与违反的边（几何定位）；
- 逐边条件在同一 (x0, psi0) 下的结果（用于展示"逐边通过但同时不通过"）。

## 3. 对判据 P1–P5 的影响

判据**不变**，但需明确其作用对象：

| 判据 | 修订后的具体含义 |
| --- | --- |
| P1 自检 | 单条直线边界（多边形退化为两条平行边）：任取 x0 于缩放层上，`maxV ≤ 0` |
| P2 复现 | 对齐矩形、w = 0、x0 取缩放层顶点：逐边 margin = 0（与 EXP-27/22 一致） |
| P3 收敛性 | `maxV` 在 psi0 网格加密下稳定（< 1e-7 m） |
| P4 判据 | `maxV ≤ 1e-9` → H-A；`> 1e-9` → H-B |
| P5 几何定位 | 若 H-B，报告违反的 x0、方向范围与顶点角的关系 |

## 4. 新增判据 P6（本修订引入）

| 编号 | 判据 | 含义 |
| --- | --- | --- |
| **P6 对照** | 在同一 (x0, psi0) 上，**逐边条件全部通过**而**同时条件不通过** | 这是 H-B 的最强证据形式；若成立，直接证明 EXP-27 的逐边判据不足 |

P6 是"逐边 ⇒ 同时"缺口是否真实的**直接检验**，比单独报告 maxV 更有说服力。

## 5. 必须声明的局限（预先写入）

1. 主分析只在**缩放层顶点**上检查。虽然该处是最坏候选，
   **本实验不构成"所有位置均已检查"的证明**（那是连续的，
   需要解析论证或更密的采样）。补充采样用于缓解，但不等于证明。
2. 沿用 EXP-21/27 的口径：转弯在 `v·n ≤ 0` 时停止，不做后续机动规划。
   真实控制器可能做得更好（多段机动），故本实验给出的是**悲观界**。
3. 不引入新物理（无延迟、无滚转动力学）——那些属 EXP-26。

3. 本修订文件先于结果提交；
4. 修订原因保留在案（原预注册未规定位置）。
