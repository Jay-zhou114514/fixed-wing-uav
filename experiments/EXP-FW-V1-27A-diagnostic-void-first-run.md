## 2. 根本原因：把不同的轨迹混在一起取 max

第一版的 `R_matrix` 按 EXP-21/27 的口径计算

```text
R_e(sign; psi0) = d(τ_e)·n_e,   τ_e = 首个使 v(t)·n_e ≤ 0 的时刻
```

即**对每条边各自**决定"转到什么时候停"。

**缺陷**：`τ_e` 依赖边 e。因此 `R_e` 对不同的 e 对应**不同的物理轨迹**：

- 对边 1 取 `τ_1`，得到的是"转到 v·n_1 ≤ 0 为止"这条轨迹；
- 对边 2 取 `τ_2`，得到的是**另一条**轨迹。

一次真实机动只有**一个**转弯时长 T。把不同 e 的 `R_e` 放在一起取
`max_e`，等于假设飞机可以同时执行多条不同轨迹——**物理上不成立**。

EXP-21/27 的单边分析不受影响（只有一个 e，不存在混淆）；
但多边情形下该写法失效。

## 3. 修正方向：直接轨迹判据（无歧义）

放弃 `required/given` 抽象，改用**直接的越界判据**：

```text
飞机位置 x(t) = x0 + d(t)
越界  ⟺  存在边 e 与时刻 t： n_e·x(t) > c_e
```

机动（单一转弯方向 + 单一转弯时长）：

```text
对 (psi0, sign, T)：飞机以最大速率按 sign 转向，持续 T，之后直飞。
在 t ∈ [0, T]（转弯段）内检查是否越界。
T 在 [0, 2π/ω]（一个整圈）内取最优。
```

对给定 (psi0, sign) 与位置 x0：

```text
M_e(T)   = max_{t ≤ T} n_e·d(t)              （累积最大，随 T 单调不减）
viol(T)  = max_e [ M_e(T) − (c_e − n_e·x0) ] （超出可用距离即为越界量）
V(x0,psi0) = min over sign, T of viol(T)
同时充分 ⟺ 对所有 (x0, psi0)：V ≤ 0
```

**该判据无歧义**：`d(t)` 是唯一一条轨迹，T 是唯一的机动参数；
`M_e(T)` 用累积最大而非各边各自的最优时刻。

**验证该修正的正确性**：P1（直线边界、飞机位于缩放层边中点）必须无违反。
若仍违反，则修正仍不成立。
