## 1. 契约（事后补写，标注为 post-hoc）

- **Hypothesis**：Stevens & Atkins (2020) 的围栏缓冲构造
  （δu = R 全向，加沿风向的单向 δd）是否包含固定翼在常值风下的真实可达集？
- **Model**：水平面 3 自由度点质量；空速 Va 恒定；最大转弯角速率 ω；常值风 W；
  机动时长上限取一个完整转弯周期 T = 2π/ω。
- **Method**：对凸集 C，S ⊆ C ⟺ 对一切方向 n 有 h_S(n) ≤ h_C(n)（支持函数比较）。
  h_S(n) 用数值最坏情况求得：**对初始航向取最坏、对转弯方向取最优**
  （接管控制器会选择更有利的一侧）。
- **Metrics**：
  - 需求 h_S(n)（各方向所需的最小缓冲）
  - 论文给 h_C(n) = R + δd · max(0, cos∠(n, φd))
  - 缺口 = h_S(n) − h_C(n)，取各方向最大值
- **Rule**：w = 0 时需求必须恒等于 R（自检）；缺口 > 0 即该方向缓冲不足。

## 4. Observation（观察到什么）

1. w ≤ 0.31 时，论文构造在各方向均覆盖最坏需求，缺口为 0。
2. w ≥ 0.32 时出现正缺口，且随风速单调增大。
3. 缺口集中出现在沿风轴的方向（358°）。
4. 需求随风速的增长快于论文缓冲的增长：w=0.5 时 3.481 R 对 2.913 R。

## 8. 第 III 节核对结果（2026-09-17 补）

读完第 III.B 节后，构造还原得到核对，并有一处重要修正。

**论文的实际构造**（式 17–20）：

1. 每条边**沿自身外法线向外平移 δu**（式 16–17：顶点沿角平分线位移 h = δu / sin(θ/2)）。
2. 当该边外法线与风向的同向分量为正时，**再沿风向平移 δd**（式 18–20）。
3. 新的顶点取相邻两条平移后直线的交点。

因此，在方向 n 上：

```text
n 恰好等于某条边外法线时：  实际缓冲 = δu + δd · max(0, cos∠(n, φd))   ← 与我的模型一致
n 落在两条边法线之间时：    实际缓冲 ≥ 上式的值（顶点处更大）
```

**结论**：我的模型是实际构造的**下界**，不是等值。这带来两点修正：

- **修正一**：正缺口只有在"围栏存在一条外法线沿风向的边"时才成立。
  矩形围栏就是这种情况，而且是最常见的围栏形状。所以缺口并非只在特殊几何下出现。
- **修正二**：对边法线都远离风轴的围栏，多边形近似带来的额外余量可能把缺口吃掉。
  这正好是一条可检验的预言：**缺口是否依赖于围栏边法线与风向的相对角度。**

第 III 节的其他核对：论文对大面积顶角用"压平边"（式 21–24）替代圆弧以回收可用空域，
并用式 25–29 比较两种实现回收的面积。这部分不改变缓冲的方向性结论。

## 9. 附：本次运行中发现并修正的两个错误（保留记录）

- 错误一：初版判据对**任意初始航向**求最坏。这导致 w=0 时也报出 41 m 缺口。
  修正：接管控制器会选择更优转弯方向，应"对初始航向取最坏、对转弯方向取最优"。
  修正后 w=0 需求恰为 R，与论文 δu 一致。
- 错误二：位移公式漏掉转弯方向因子。积分 ∫cos(ψ0 + sign·ωt) dt = sin(·)/(sign·ω)，
  初版漏了 1/sign，导致右转轨迹符号错误，w=0 需求被算成 2R。
- 两次都是**自检（w=0 必须等于 R）**发现的。自检必须保留。
