## 2. **四处需要更正的记录**（本次核验的主要产出）

### 2.1 我们引用的原文**逐字准确** ✓

§3.4 引文（"driven towards the vertex … eventually penetrate the fence … unable to
complete a full turn, as the turning circle c₁ extends out of the geozone"）
与原文**一致**。此前记录**无需修改**。

### 2.2 ⚠ 更正一：**该文不是"仅二值判据"，它有成型的闭式**

此前记录（`LITERATURE_MAP` §3.7.1）称"该文给出的是二值判据（相交/不相交），
未给出穿透量公式"，并把 `penetrat*` 一律标注为"定性二值判断"。**这在整体上过宽。**

**该文实际给出闭式**：

```text
式 10   s_min = r(cscθ − cotθ) = r·tan(θ/2)        ← 直边接近时的**转向触发距离**闭式
式 11   r = V²/(g·tanφ_max) = G·V²
式 12   s_min = G·V²(cscθ−cotθ) + s_t              ← 含瞬态
式 13   r' = r + s_t                               ← 转弯圆检验用的膨胀半径
```

**但**：这些闭式针对的是**直边接近**（单条围栏的"何时开始转"），
**全文（本次覆盖部分）未给出顶点穿透深度、也未给出死区范围的闭式**。

**修正后的准确表述**：

> 该文对**直边接近**给出转向触发距离闭式 `s_min = r·tan(θ/2)`，
> 对**锐角顶点**则仅作定性判断（"终将穿透"、"可能无法避免"），
> **未给出穿透深度或死区范围的任何闭式**。

**对 K8/K9 的影响：无。** 仍未见他人发表穿透深度或死区闭式。

### 2.3 ⚠ 更正二：**其"同时判据"比我们记录的更强、更完整**

此前记录称该文"对每个候选转弯方向检查所有相邻围栏"。
**实测其 §3.4 是一个完整的三围栏 × 两转弯圆联合检验**：

| 检验 | 内容 |
| --- | --- |
| (i) | 转弯圆圆心到围栏**大圆平面**的垂距 < `r'` |
| (ii) | 该围栏两节点是否**跨立**圆心（排除"圆与延长线相交但在区间外"） |
| (iii) | 圆心到各节点的距离 < `r'`（补救 (ii) 的漏判） |
| **判据** | `(i ∧ ii) ∨ iii`，对 **每条围栏 × 每个转弯圆**评估；任一满足即判为已越界 |

**且该文明说**：在锐角处"若在 `s⁺ ≤ s_min` 时才转向（即**只按当前那条边**判），
则转弯圆 c₁ 伸出 geozone"——**这正是"逐边判据不充分"的陈述**。

**因此**：
- **D17（不主张首次提出同时判据）成立无疑**；
- 本项目 EXP-27A 的"逐边 ≠ 同时"属**对该机制的独立复现**，
  增量仅为：**穿透量 0.87 R 的定量给出** + **闭式律** + **对本构造（JAIS δu⊕δd）的否证**。

### 2.4 ⚠ 更正三（**影响论文核心表述**）：空速无关性是**模型条件性的**

该文的转弯半径是**协调转弯**式：`r = V²/(g·tanφ_max) ∝ V²`。

而本项目的 `R = Va/ω` 把**最大转弯率 ω 当作给定常数**。
两者在物理上可统一——协调转弯下 `ω_max = g·tanφ_max/V`，
故 `R = Va/ω_max = V²/(g·tanφ_max)`，**与该文一致**。

**关键推论**：

| 转弯模型 | 转弯半径 | 允许延迟 `τ ≈ 余量 / 地速` |
| --- | --- | --- |
| **本项目（ω 固定）** | `R ∝ V` | `τ ∝ V⁰` → **与空速无关** |
| **协调转弯（该文）** | `R ∝ V²` | `τ ∝ V` → **与空速有关** |

> **因此"允许延迟与空速无关"是"最大转弯率 ω 固定"这一理想化假设的产物，
> 不是通用工程性质。** 论文与申报书**必须**写明该前提；否则遇到熟悉协调转弯的
> 审稿人会被直接指出。
>
> 这不推翻 K1/H2（它们在所述模型内**正确且已数值验证到机器精度**），
> 但**限定了它们的适用范围**。已登记 **D20**。

### 2.5 ⚠ 更正四：其瞬态补偿是"**距离**"，我们是"**时间**"；且其 §4.3 未覆盖

| | Thomas 2024 | 本项目 |
| --- | --- | --- |
| 瞬态修正的**形式** | **加距离**：`r' = r + s_t`（膨胀转弯半径） | **减时间**：`τ_crit = τ_base − τ_roll` |
| 参数来源 | 摘要："closed-loop rise time in roll command tracking" | 一阶滚转时间常数 `τ_roll` |
| 效果 | 增大转弯圆 → 提前触发 | 直接扣减允许延迟 |

**两者物理来源相同（滚转上升时间），但修正量的形式不同**，
故本项目 H3 **不构成对其的重复**（但也不能主张"首次把滚转瞬态纳入围栏判据"——D4/D-既有）。

**诚实标注**：我们此前的记录（`EXP-FW-V1-26-armR.md` 与审计）曾写
"该文 §4.3：`s_t = V·t_c`"。**本记录无法核实该式**——**§4.3 不在本次提供的文本内**。
该引用须在拿到 §4 后复核，或改为不含具体式的表述。

## 6. Observation / Interpretation / Limitation

### Observation

1. §3.4 引文与我们的记录**逐字一致**。
2. 该文给出 `s_min = r(cscθ−cotθ) = r·tan(θ/2)`（式 10）等**直边**闭式。
3. 其锐角处理是**三围栏 × 两转弯圆**的联合检验（判据 `(i∧ii)∨iii`）。
4. 其转弯半径为协调转弯式 `r ∝ V²`。
5. 其瞬态补偿为**距离** `s_t`（式 12/13），源自滚转指令跟踪的闭环上升时间。
6. 该文**不建模风**；**处理凹多边形与极地**。
7. 全文（本次覆盖部分）**无顶点穿透深度、无死区范围**。

### Interpretation

- **K8/K9 仍未被覆盖**，且该文明确承认锐角处的困难（只是未量化）；
- **K4'/EXP-27A 的机制已被该文实质覆盖**，本项目增量在**定量**（0.87 R + 闭式）；
- **K1/H2 的空速无关性必须降格为"模型条件性结论"**（新增 D21）；
  这不影响其内部正确性，但影响其对外表述强度；
- 该文的"算法 vs 刻画"差异使两者可并列引用，无需回避。

### Limitation

1. **§4（量化结果、`s_t` 的确定方法）与 §5 未在提供的文本内**，
   故①"该文无穿透量公式"的结论**限于本次覆盖范围**；
   ② 我们此前"`s_t = V·t_c`"的引用**无法核实**，须复核或删除具体式；
2. 未核对其 refs [22,23,24] 是否即 JAIS 2020；
3. 未获取 §4 的仿真场景参数，故无法比较两者数值；
4. 本记录**不评价**该文算法优劣。
