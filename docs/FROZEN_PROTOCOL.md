## 1. 运动学模型

| 项 | 冻结内容 |
| --- | --- |
| 维度 | 3 自由度水平面点质量（`x, y, ψ`）；**不含**高度、气动、失速 |
| 空速 | 常值 Va，单位 m/s；参数网格见 §4 |
| 转弯 | 常滚转，最大转弯角速率 ω，单位 °/s；对应最小转弯半径 R = Va/ω |
| 风 | **常值风** W，风速比 w = |W|/Va；`[待 S1]` 阵风与风切变在 S6 之前不进入主分析 |
| 地速 | v_g = Va·e(ψ) + W |
| 地面曲率 | κ_g = Va·ψ̇·(Va + W·e_ψ)/|Va·e_ψ + W|³ （EXP-FW-V1-02 已解析+数值互验） |

**边界声明**：所有结论必须自带"3-DOF 水平面点质量、常值风"的限定。
任何超出该模型的推广只能写在 Limitation。

## 2. 机动集与动作定义

| 项 | 冻结内容 |
| --- | --- |
| 动作空间 | **离散机动词表**（Dubins 族有限子集），这是本项目非凸性的来源，不得替换为连续优化 |
| 词表粒度 | `[待 S1 实测冻结]`（建议初值：航向增量 15°，长度按 R 归一） |
| 动作的当前代价 J | 时间 / 能耗 / 路径长度的加权和；权重 `[待 S1 实测冻结]`，且**权重只能由训练场景确定** |
| 不可逆性 | 一旦执行动作，位置与航向不可瞬时改变（非完整约束）；这是固定翼与多旋翼的分界 |

**禁止**：为方便实现而把动作空间改成连续可微的（会消灭非凸性，直接导致 G4 失败与假阴性）。

## 3. F（未来可行空间）的三档定义

三档由简到繁，S0→S2 逐级替换。**同一实验内不得混用不同档**；混用必须在记录中声明。

| 档 | 定义 | 冻结要求 |
| --- | --- | --- |
| **F-1** | `N_feasible_future_maneuvers`：执行动作 a 后，词表中仍满足"不越界且可保持安全"的机动个数 | 需冻结"仍可行"的判据（安全集合定义见 §5） |
| **F-2** | 未来可达状态集的**网格体积**：在 (x, y, ψ) 网格上统计动作后可达且安全的格子数 | 需冻结网格分辨率 `[待 S1 实测冻结]` |
| **F-3** | Monte Carlo：`N_成功未来任务 / N_测试未来子场景` | 需冻结子场景数与随机种子序列；**必须先报功效** |

**一律不采用**：高维 Hamilton–Jacobi 可达性、完整 6-DOF、真实气动。

## 5. 安全与可行性判据

| 项 | 冻结内容 |
| --- | --- |
| 安全集合 | 围栏内 + 无障碍碰撞（围栏与障碍定义见场景生成器，参数写死在 `src/config.py`） |
| "当前安全" | 执行动作 a 后，存在至少一条使飞机保持安全的后续控制序列 |
| 余量口径 | 沿用 EXP-FW-V1-22：构造余量恒为 δu = Va/ω |
| 延迟 | 接管延迟 τL 的定义沿用 EXP-FW-V1-22；临界值 τL\* = 1/(ω(1+w)) |

## 6. 决策规则（本项目核心比较）

| 代号 | 规则 |
| --- | --- |
| A_myopic | `argmin J(a)` |
| A_penalty | `argmin (J(a) − λ·F(a))`，λ ≥ 0 |
| **A_constraint** | `argmin J(a) s.t. F(a) ≥ F_min` |

**并列处理规则（确定性）**：F 相同时取 J 更小者；J 也相同时按词表冻结顺序取更靠前者。
不得使用随机 tie-break。

## 7. 场景与划分

| 项 | 冻结内容 |
| --- | --- |
| 生成器 | 程序化生成，固定种子；参数范围预先写死 |
| 划分 | **训练 / 验证 / 测试场景集三分**；测试集只开一次 |
| **独立单元** | **场景族（block）**；同一族内场景共享生成器参数 |
| 伪重复防御 | 同族场景**不得**当作独立重复；分析用混合模型或分层聚合 |
| 种子 | 每格 ≥ 3 个随机种子，种子为重复层级 |

**硬纪律**：规划参数、安全裕度、F_min、判据**只能用训练/验证场景确定**。

## 8. 非凸性验证（G4，本项目特有）

**在跑任何比较实验之前**，必须报告场景的**权衡集凸性指标**：

1. 对场景中的候选动作集，计算 (J, F) 点集的凸包；
2. 报告落在凸包内部（即被凸组合支配）的 Pareto 点数占比；
3. 报告 Pareto 前沿中**非支撑点**的数量与占比；
4. 判据：若非支撑点占比 ≈ 0，则该场景**不能**用于 H2 检验，必须重新设计场景。

**理由**：凸权衡集下 A_constraint 与 A_penalty 必然给出相同结果
（见 `notes/CHAIN_C_THEORY_NOTE.md`），会产生无法解读的假阴性。

## 9. 报告格式（五维，迁移自 Motor）

| 维度 | 指标 |
| --- | --- |
| Performance | 任务成功率 / 假安全率 / 路径长度比 |
| Decision comparison | A_myopic vs A_penalty(λ最优) vs A_constraint 的选择差异率 |
| Non-convexity | 非支撑点占比、凸包支配率（§8） |
| Cost | F 估计耗时、规划耗时、拟合次数 |
| Generalization | 换场景族 / 换参数区间后结论是否成立 |

## 10. 证据等级

| 等级 | 含义 | 允许出现的位置 |
| --- | --- | --- |
| A | 多独立单元 + 预注册 + 完整产物 | Abstract / Conclusion |
| B | 单一体系或单一划分，效应方向清楚 | Results（须标注限制） |
| C | 单点观察 / 后验发现 / 有限算例 | 只能写为线索 |
| D | 功效不足或与噪声基准不可区分 | 只能写为 limitation |

**C / D 级证据不得进入 Abstract 与 Conclusion。**

> 因此**目前不得写入任何正式结论**。

### 12.1 三件套要求（2026-09-18 新增，因四次无效结果而立）

**任何进入结论的量，必须同时具备以下三项验证，缺一即不得讨论、不得进入结论：**

| # | 验证 | 作用 |
| --- | --- | --- |
| (a) | **负对照** | 在应成立处确实无异常 |
| (b) | **正对照** | 判据**有检出能力**（能报出应报的异常） |
| (c) | **与既有独立实现的交叉验证** | 同一量由两条独立路径算出应一致 |

**为什么必须三条**（本项目已发生四次无效结果）：

| 次数 | 实验 | 表面结论 | 实际原因 | 被哪一项拦住 |
| --- | --- | --- | --- | --- |
| 1 | EXP-27 首轮 | 最坏构型为随机多边形，margin 0.11 m | 航向网格离散化伪影 | (c) |
| 2 | EXP-27A v0 | H-B 成立，35.7 m 同时违反 | 混用不同轨迹（各边用各自的 τ_e） | (a) |
| 3 | EXP-27A v1 | 判据通过 | **平凡通过**，无检出能力 | (b) |
| 4 | EXP-27A v2/v3 | 全 +∞ / 与 EXP-27 差 12.9 m | 机动模型与时间视界未定义 | (a)(c) |

**规则**：

1. **自检失败 ⇒ 主结论一律作废，不得讨论**（不得因"结论有意思"而保留）；
2. **只有负对照的验证不合格**——必须证明判据**能**报出异常（v1 的教训）；
3. 若无既有独立实现可交叉验证，须在预注册中说明并给出替代验证方案；
4. 失败与作废记录保留在案（`CONVENTIONS.md` 第 5 节）。

### 12.2 量必须良定义（2026-09-18 新增）

进入结论的量不得依赖**任意选择的参数**。

**实例**：EXP-27A 的"整周期最大穿透"依赖周期长度——常值风下盘旋轨迹是**开口的**
（顺风漂移），穿透量随圈数**线性增长**（w=0.3 时：1 圈 77.8 m → 10 圈 777.6 m）。
该量不良定义，其"结果"只是所选视界的产物。

**检查方法**：对量中的每个自由参数（视界、网格、采样范围）做单调变化；
若结论随之系统性变化，则该量不良定义，必须重新定义。

### 12.3 机动模型与时间视界必须显式规定（2026-09-18 新增）

凡涉及"安全/越界"的实验，预注册中必须显式写定：

1. **时间视界**：检查多长时间窗内的安全；
2. **机动模型**：一次转弯 / 转弯后直飞 / 持续盘旋（并说明物理依据）。

**注意**：常值风 + 持续盘旋 ⇒ 顺风漂移必然出界（与缓冲数值无关）。
因此"盘旋保证 contain"在本项目中**不成立**，不得作为验证目标。
