## 3. **新增 D19（本版增设）**

> **D19**：~~既有围栏缓冲研究忽略方向依赖、普遍假设各向同性缓冲~~
> —— 该主张**错误**，**不得**以任何形式出现。

**理由**：

1. **JAIS 2020（Stevens & Atkins）本身即使用方向性缓冲** δd，
   其 δd = R√(1−w²) + wR·arccos(−w) **明确沿风向方向**，非各向同性；
2. Kim 2022 的各向同性是其**问题设定使然**（包裹一条**已知**航迹 ⟹ 截面可用单一
   包络半径），**不是疏忽**；且其取 `max[δsby, δsbz]` 属**保守**选择（宁大不小）；
3. 两者是**不同设计哲学**（各向同性 + 统计 vs 方向依赖 + 解析），
   对应**不同问题**（缓冲尺寸设计 vs 裕度刻画）；
4. 若声称"既有工作假设各向同性"，将**同时误述 JAIS 2020 与 Kim 2022**，
   属可被一眼驳倒的表述。

**连带约束（措辞纪律）**：

| 不得说 | 应说 |
| --- | --- |
| "既有缓冲假设各向同性" | "既有**缓冲尺寸**研究（Kim 2022）在**包裹已知航迹**的设定下取各向同性截面" |
| "Kim 的缓冲过于保守/存在缺陷" | "Kim 采用**保守**的各向同性截面；本项目刻画的是**方向依赖构造**的裕度特性" |
| "我们首次指出方向依赖" | "方向依赖缓冲已见于 JAIS 2020（δd）；本项目刻画**其裕度特性**" |

**⚠ 与本项目 P0 结果的关系（须谨慎）**：
P0 发现"**以各向同性半径作为所需缓冲**，在有风时双向失效
（**顺风侧不足、迎风侧过多**）"。
**方向已于 2026-09-19 更正**（原写作"迎风不足、顺风过多"，系方向写反；
依据 `required(n)` 的方向约定：`n=0` 即顺风，其 `required = δd > R`）。
该结果刻画的是**本项目对象（JAIS δu⊕δd 构造）** 的性质，
**不得**表述为"Kim 的各项同性缓冲有缺陷"——原因见第 3 节理由 1–3。
