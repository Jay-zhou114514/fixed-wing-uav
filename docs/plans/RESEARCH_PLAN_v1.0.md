## 0. 一句话

固定翼无人机的最小转弯半径不是一个常数。有风时它是风向的函数，顺风与逆风
可以差三倍以上。而绝大多数避障规划器在**空气坐标系**里做几何校验，真正的安全
边界却在**地面坐标系**里。本项目要测出这个假设从哪一刻开始失效、失效多少，
并用最小的代价把它修回来。

---

## 1. 为什么是这个问题

### 1.1 现实背景

固定翼无人机航时长、航程远，是低空巡检、应急巡查、测绘的主要机型。它的一个
硬性物理约束是：**不能原地转弯**，任何航迹都必须满足最小转弯半径，否则计算出来
的路径根本无法执行。

工程上解决这个约束的标准做法是：把最小转弯半径当成一个常数 R，然后用 Dubins
曲线或带半径约束的格点 A\* 做规划；避障安全裕度也在同一个坐标系里留。

问题在于：R 是**相对空气**的物理量（R = Va² / (g·tanφ_max)），而障碍物在**地面**
坐标系里。有风时这两个坐标系不重合。

### 1.2 这个项目选择的角度

不造新飞机，不做新算法堆叠，而是问一个很小、但一直含糊的问题：

> 用常数半径规划的路径，在有风时到底偏差多大？从哪一刻开始会真的撞上东西？

这个问题有三个好处：可解析推导、可完全仿真验证、不需要任何硬件。

### 1.3 目前已有的理论证据（本轮新增）

对定常空速、定常滚转的协调转弯做运动学推导，得到地面航迹的曲率：

```
κ_g = Va · ψ̇ · (Va + W·e_ψ) / |Va·e_ψ + W|³
```

于是地面转弯半径与空气系半径之比只依赖风速比 w = |W|/Va 和航向与风向夹角 θ：

```
R_g / R_a = (1 + 2w·cosθ + w²)^{3/2} / (1 + w·cosθ)
```

代入典型参数（Va = 18 m/s，φ_max = 35°，R_a = 47.2 m）：

| w | 风速 | 逆风 R_g | 侧风 R_g | 顺风 R_g | 顺/逆比 |
| --- | --- | --- | --- | --- | --- |
| 0.1 | 1.8 m/s | 38.2 m | 47.9 m | 57.1 m | 1.49 |
| 0.2 | 3.6 m/s | 30.2 m | 50.0 m | 67.9 m | 2.25 |
| 0.3 | 5.4 m/s | 23.1 m | 53.7 m | 79.7 m | **3.45** |
| 0.4 | 7.2 m/s | 17.0 m | 59.0 m | 92.5 m | 5.44 |
| 0.5 | 9.0 m/s | 11.8 m | 65.9 m | 106.2 m | 9.00 |

w = 0.3 对应 5.4 m/s（约 10 节）的风。也就是说：**一阵普通的风，就足以让
"转弯半径是常数"这个假设在量级上失效。**

这不是文字修辞。该式已用独立的数值积分做互验：对地面航迹做中心差分估计曲率，
与上面的解析式在全部 (w, θ) 组合上最大相对误差为 1.9e-7（远低于预注册判据 1e-3）。
完整的可复现实验脚本（EXP-FW-V1-02 的落库版本）尚未建立。

## 2. 核心科学问题与假设

### 2.1 核心问题

> 在什么样的风与障碍条件下，基于常半径假设的避障规划会从"保守可行"变成
> "隐蔽地不可行"？以及，把风的各向异性并入几何，是不是最小的有效修复？

### 2.2 待检验假设

| 编号 | 假设 | 检验实验 | 当前状态 |
| --- | --- | --- | --- |
| H1 | 地面转弯半径由 w 与 θ 决定，解析式成立 | EXP-FW-V1-02 | 解析推导完成 + 数值互验通过（1.9e-7），等级 A（仿真内）；脚本待落库 |
| H2 | 存在临界风速比 w\*，超过后常半径规划的碰撞率显著上升 | EXP-FW-V1-03 | 未检验 |
| H3 | 失效的主导成分是"空气系避障间隙被高估"，而非跟踪误差 | EXP-FW-V1-04 | 未检验 |
| H4 | 把各向异性半径并入几何，可用最小改动把成功率拉回 | EXP-FW-V1-05 | 未检验 |
| H5 | 风估计误差与阵风下结论仍成立（结论不依赖完美风信息） | EXP-FW-V1-06 | 未检验 |

### 2.3 反对的主张（必须主动排除）

- AC1：性能差异只来自"我们的方法用了更保守的障碍膨胀"，即靠多绕路换安全。
  → 必须报告路径长度、飞行时间的代价。
- AC2：失效只是跟踪器不好，换了更好的控制器就没有了。
  → EXP-FW-V1-04 用完美跟踪（直接速度指令）做对照，分离这部分贡献。
- AC3：结论只在极端风下成立，工程上无所谓。
  → 必须给出 w 的绝对数值区间，并对照真实风场数据说明常见性。

## 3. 技术路线

### 3.1 模型（阶段一）

水平面 3 自由度点质量模型，明确标注适用边界：

```
ẋ = Va·cosψ + Wx
ẏ = Va·sinψ + Wy
ψ̇ = (g / Va)·tanφ ,  |φ| ≤ φ_max
```

- 假设：协调转弯、无侧滑、Va 恒定（先），高度不变。
- 不含：气动、失速、动力饱和、爬升。
- 未含部分列入局限，不作为本阶段结论的一部分。

### 3.2 基线与方法

| 代号 | 角色 | 说明 |
| --- | --- | --- |
| B0 | 下界 | 直线航点 + 纯追踪，不做避障 |
| B1 | 主基线 | 航向格 A\*，常半径运动基元（直行/左满舵/右满舵），忽略风 |
| B2 | 主基线 | 解析 Dubins（6 族曲线最短），忽略风 |
| B3 | 方法 | 风感知几何：在规划代价中使用 R_g(w, θ) 或各向异性可达集 |
| B4 | 参考上界 | 小规模数值最优（MPC / 直接配点），只跑少量场景 |
| B5 | 可选 | 安全过滤层：把不可行指令投影到可行集 |

只在 B1–B3 之间做正式对照。B4 用于回答"最优能好多少"，B5 属于阶段二入口。

### 3.3 场景生成与数据分离

全部场景程序化生成，固定随机种子，**场景集分离**（对应项目一的按文件划分）：

| 集合 | 用途 | 规模 | 规则 |
| --- | --- | --- | --- |
| train | 调参、选策略 | 200 | 可反复使用 |
| val | 选阈值、选模型 | 100 | 使用次数记录在案 |
| test | 只在最后打开一次 | 300 | 一旦使用即封存 |

场景参数空间：

```
风速比 w         : 0 – 0.5（步长 0.05）
风向            : 0° – 360°（步长 30°）
障碍密度        : 低 / 中 / 高
障碍尺度        : 相对 R_a 的 0.5x / 1x / 2x
规划安全裕度 m  : 0.25R_a / 0.5R_a / 1.0R_a
起终点姿态差    : 小 / 中 / 大
```

### 3.4 评价指标

主指标（决定结论）：

- **任务成功率**：在时限内到达目标且全程无碰撞。
- **实际最小障碍间隙**（按地面航迹计算），及其与规划预测间隙之差 Δ_clearance。
- **间隙高估量** Δ(w, θ)：这是本项目要刻画的物理量。

次指标（决定代价是否可接受）：

- 路径长度、飞行时间、控制量变化总量（能量代理）、规划计算时间、航迹平滑度。

违规量（安全诊断）：

- 最小转弯半径违反次数、滚转饱和时长、空速越界时长。

**绝对不允许只报最好的一次。**所有随机场景报均值、标准差与置信区间。

## 4. 实验设计（claim → evidence → run order）

### 主张映射

| 主张 | 为什么重要 | 最小可信证据 | 关联实验 |
| --- | --- | --- | --- |
| C1 常半径假设存在量级级别的几何误差 | 这是项目的立足点 | 解析式 + 数值互验 + 各向异性相图 | 02, 03 |
| C2 误差会转化为真实碰撞而不是"更保守" | 决定工程价值 | 在 test 场景集上碰撞率随 w 单调上升 | 03, 04 |
| C3 失效机制可归因于坐标系不一致 | 决定方法能否对症 | 受控干预分离间隙与跟踪误差贡献 | 04 |
| C4 最小修复有效且代价可接受 | 决定是否有方法贡献 | w > w\* 区间成功率回升，且路径长度代价有界 | 05 |
| C5 结论不依赖完美风信息 | 决定是否只是仿真艺术 | 风估计误差/阵风下的前瞻验证 | 06 |

### 实验块

#### EXP-FW-V1-01 常半径规划与评价管道一致性

- 检验主张：无（正确性检查）
- 为什么存在：所有后续结论依赖度量管道正确
- 场景：无风无障碍，10 组相对几何
- 对照：航向格 A\* vs 解析 Dubins vs 解析解
- 指标：路径长度比、末端位置/航向误差、间隙计算误差
- 成功判据：长度比 ≤ 1.05，末端位置误差 < 0.5 m
- 失败含义：代码有误，不得推进
- 优先级：MUST-RUN

#### EXP-FW-V1-02 地面转弯半径各向异性定律

- 检验主张：C1
- 场景：w × θ 网格，常滚转三整圈
- 指标：κ 解析 vs 数值、R_g/R_a 极坐标图、各向异性比
- 成功判据：最大相对误差 < 1e-3；w = 0.3 时顺逆比 > 3
- 失败含义：运动学实现有误，或定律本身不成立（后者会改变整个项目）
- 优先级：MUST-RUN
- 当前状态：解析式已推导，并已用一次性数值积分互验通过（最大相对误差 1.9e-7，
  w = 0.3 时顺逆比 3.45）。**可复现脚本、CSV、图尚未落库**，因此本实验在形式上
  仍是「部分完成」，不得引用为正式实验结论。

#### EXP-FW-V1-03 常半径规划的失效边界相图

- 检验主张：C1、C2
- 场景：train + val 上扫描 (w, 风向, 障碍密度, 裕度)，找出边界；test 上确认
- 对照：B1 / B2 / B3 / B4
- 指标：成功率、碰撞率、Δ_clearance、路径长度代价
- 成功判据：存在 w\*，使得 w < w\* 时碰撞率 < 5%，w > w\* 时碰撞率 > 20%；且 w\* 随裕度单调
- 失败含义：常半径假设在实用风下足够安全 → 项目失去立足点，按 Stop 1 转向
- 表/图目标：主图 1（(w, 风向) 平面上的成功/碰撞相图）
- 优先级：MUST-RUN

#### EXP-FW-V1-04 失效归因的受控干预

- 检验主张：C3
- 设计：三种受控设置——(a) 完美跟踪 + 空气系校验，(b) 有跟踪误差 + 空气系校验，
  (c) 完美跟踪 + 地面系校验。逐项比较碰撞率。
- 指标：碰撞率分解、Δ_clearance 分解
- 成功判据：(a) 的碰撞率显著高于 (c)，且 (b) 与 (a) 之差小于 (a) 与 (c) 之差
- 失败含义：失效主要来自跟踪误差 → 方法应转向控制器，而非几何
- 优先级：MUST-RUN（决定 EXP-05 的方向）

#### EXP-FW-V1-05 风感知规划的最小修复

- 检验主张：C4
- 对照：B1/B2（常半径）vs B3（风感知），同一 test 场景集
- 指标：成功率、Δ_clearance、路径长度代价比
- 成功判据：w > w\* 区间成功率相对提升 ≥ 30 个百分点，路径长度代价 ≤ 15%
- 消融：只用各向异性半径 / 只用障碍膨胀 / 两者都用
- 失败含义：需要更完整的可达集表示，进入阶段二
- 优先级：MUST-RUN

#### EXP-FW-V1-06 泛化与鲁棒性前瞻验证

- 检验主张：C5
- 设计：风估计误差（偏差、噪声）、阵风、风切变；训练场景与测试场景分离
- 判据：预注册判据在实验前写死
- 优先级：MUST-RUN（结题必需）

#### 刻意不做

- 多机集群：规模失控，列为项目三候选。
- 真实飞机试飞：成本与合规风险高，列为可选加分项，不作为证据链必需环节。
- 端到端深度强化学习：在 C3 结论出来之前做，属于先定方案再找问题。

## 6. 实验规范（沿用项目一）

1. **先预注册再运行。** 写清假设、指标定义、场景划分、判据、判定规则，提交后才跑。
2. **只用训练/验证集选参。** 阈值、裕度、超参数只能来自 train/val；test 只打开一次。
3. **禁止测试集调参。** 用过了就标 *post-hoc*。
4. **证据等级。** A = 本仿真中受控结果；B = 一致，待确认；C = 未确立（如置信区间重叠）；
   D = 未知。等级 C/D 的结论不得写进摘要或结论。
5. **三层次报告。** 观察 / 解释 / 局限三层分开，绝不把解释写成观察。
6. **保留失败。** 失败的实验和负结果都留着，并分析。
7. **机制 ≠ 相关。** 没有受控干预，不得把相关说成机理。
8. 每个实验交付五项：**结果、脚本/日志、CSV、图、初步理解**。
