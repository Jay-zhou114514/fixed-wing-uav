## 0. v1.0 为什么作废

v1.0 的题目是"风扰下常半径规划的可执行性失效边界"。经三轮检索（Scopus 约 50 组、
OpenAlex 36 组、arXiv 11 组、Crossref 6 组），该方向被证伪为已被占据：

- 风下最优路径问题：2005 提出 → 2009/2012 解强风 → 2018 处理不确定风
  → 2023（RA-L）/2025（JGCD）给出分类解与闭式解。**已解决**。
- "转弯半径与风决定安全缓冲区"：AIAA JAIS 2020 已发表（`10.2514/1.i010792`），
  摘要原文即"缓冲区是最小转弯半径与持续风的函数"。**已被抢先**。
- "固定翼 + 安全保证"措辞：Control Engineering Practice 2026 已用。
- "可认证安全规划"框架：Drones 2026 综述（`10.3390/drones10050351`）已命名。

v1.0 保留在 `RESEARCH_PLAN_v1.0.md`，作为被推翻方向的记录，不删除。

**教训**：本领域的"想一个点 → 查是否被占"策略命中率接近零。
v1.1 改用"文献预期 vs 实验实测之差"来产生问题。

## 1. 战略判断：拥挤领域怎么打

这个方向在低空经济推动下是全球最拥挤的研究方向之一。以本科生的资源正面竞争新算法，
期望收益极低。可打的仗只有一类：

> **用更严的评估协议，去检验该领域已经发表的结论。**

理由有三条：

1. 该领域近年产出暴增（本次 187 条语料中 25 条标题含强化学习），产出速度远快于
   评估规范的建立速度。
2. 仿真研究有一个系统性弱点：**伪重复**——把同一场景族里相关的场景当作独立样本，
   由此虚报统计效力。这类问题在领域内大规模存在是高度可能的。
3. 这正好是项目一（motor-health-monitor）已经验证过的能力：
   预注册、训练集独立选参、功效分析、证据等级、三层次报告、保留负结果。

**所以本项目的贡献类型是"评估与最小修复"，不是"新算法"。**

| 代号 | 方向 | 形态 | 新颖性状态 | 风险 | 定位 |

## 3. 核心科学问题与假设

### 3.1 核心问题

> 固定翼规划器在**空气坐标系**里保证的障碍间隙，是否等于实际飞行的**地面坐标系**间隙？
> 如果不是，误差有多大、由什么因子主导、能否用一个解析界把它修回来？

### 3.2 定义

```text
Δ = 规划器预测的最小障碍间隙 − 实际地面航迹的最小间隙
假安全 = Δ < 0 的那些运行
```

### 3.3 待检验假设

| 编号 | 假设 | 检验阶段 | 状态 |
| --- | --- | --- | --- |
| H1 | Δ 系统性非零，且随风速比 w 单调增大 | EXP-FW-V1-07 | 未检验 |
| H2 | Δ 的主导因子是风与转弯方向的组合，而不是障碍密度 | EXP-FW-V1-08 | 未检验 |
| H3 | Δ 的符号与量级可由地面扫掠集包络解析预测 | EXP-FW-V1-09 | 未检验 |
| H4 | 用该解析界做障碍膨胀，可把假安全率降到给定水平，且路径长度代价有界 | EXP-FW-V1-10 | 未检验 |
| H5 | 结论在分布外场景族与风估计误差下仍成立 | EXP-FW-V1-11 | 未检验 |

### 3.4 必须主动排除的替代解释

- AC1：Δ 只来自跟踪误差，不是几何记账错误 → S3 用"完美跟踪"对照组分离。
- AC2：Δ 只在极端风下成立，工程上无所谓 → 必须给出 Δ 随 w 的绝对数值。
- AC3：假安全意识只是我选的场景生成器造成的 → 场景生成器公开，参数范围预先写死。

## 4. 设计成"两种结果都可发表"

这是本项目最重要的策略决定。

| 结果 | 论文形态 |
| --- | --- |
| Δ 显著非零 | "现行风感知规划在安全记账上系统性偏差：证据、主导因子与最小修复" |
| Δ 不显著 | "统一协议下检验固定翼风扰规划的安全声明：未发现偏差，给出可复现基准与适用边界" |

第一种是发现型论文，第二种是确认型论文。**两者都发得出去。**
反过来，若设计成"只有我的方法赢了才成立"，失败即零产出。

## 5. 执行阶梯 S0–S6（从简单到困难）

每级都有出口条件，未过不进下一级。这是"从简单到困难"的落地方式。

| 级 | 目标 | 产出 | 出口条件 | 预计工期 |
| --- | --- | --- | --- | --- |
| **S0** | 最小可跑：常滚转转弯 + 常值风 + 地面航迹 | 曲率解析式与数值互验 | 相对误差 < 1e-3 | 已完成（未落库） |
| **S1** | 可信平台：运动学 + 场景生成器 + 两个几何规划器 + 统一度量 | `src/` 全套 + 单元测试 + EXP-FW-V1-01 | 无风无障碍下与解析解一致，路径长度比 ≤ 1.05 | 2–3 周 |
| **S2** | 审计：测 Δ 与假安全率 | EXP-FW-V1-07 + 筛查设计 | Δ 可重复，跨种子稳定 | 3–4 周 |
| **S3** | 归因：受控干预分离因子 | EXP-FW-V1-08 | 能指出主导因子，排除 AC1/AC3 | 3–4 周 |
| **S4** | 机制：地面扫掠集包络的解析预言 | EXP-FW-V1-09 | 预言与仿真一致，且可被证伪 | 3–4 周 |
| **S5** | 修复：最小改动的膨胀界 + 消融 | EXP-FW-V1-10 | 假安全率降到目标，路径代价有界 | 3–4 周 |
| **S6** | 泛化：分布外场景族 + 风估计误差 + 功效分析 | EXP-FW-V1-11 | 结论在训练条件外仍成立 | 4 周 |

**设计要点（来自 experimental-design）**

- S2 用 Plackett–Burman 筛查 7 个因子（风速比、风向相对转弯、障碍密度、障碍尺度、
  规划安全裕度、规划器族、转弯方向序列），只需 8–12 组。
- S3 对主导的三因子做 2³ 全因子 + 区组。
- **场景族是区组，不是独立样本。** 同族场景共享生成器参数，把它们当独立样本就是伪重复。
  风与安全裕度在族内随机化，每格 ≥ 3 个种子，分析用混合模型或分层聚合。
- S2 之前先做功效分析，确定族数与种子数。

**技术选择**

- 第一阶段只用几何规划器（常半径 Dubins、航向格 A*、风感知变体），纯 CPU、可复现。
- RL 策略推迟到 S6 之后，避免训练不稳定与算力需求拖住主线。
- 模型为水平面 3 自由度点质量，适用边界明确写进局限。

## 7. 论文路线

### 7.1 会议论文骨架（2027-03 投稿）

- 标题方向：统一协议下固定翼风扰规划的**地面系安全记账**审计与最小修复
- 贡献一：统一评估协议 + 可复现场景生成器 + 一批规划器的横向审计
- 贡献二：Δ 的主导因子与受控归因
- 贡献三：地面扫掠集包络的解析界，以及把它作为膨胀界接在现有规划器上的实验
- 目标会议：CCC / CCDC / ICUAS / ICUS 一类（需核实当年截止日期）
- 证据要求：跨种子稳定、报均值与置信区间、消融、代价分析

### 7.2 期刊扩展（2027-07 起）

在会议版基础上加四块：

1. 风估计误差从"已知"→"有界"→"概率化"，出机会约束版本。
2. 常值风 → 阵风与风切变。
3. 加高度通道与能量约束。
4. 与管式 MPC / CBF 安全层对照；有条件时补半实物或真机数据。

目标期刊：Drones（该子领域主场，本次语料中 20 篇）、Aerospace、
IEEE Access 一类。会议与期刊必须按"扩展政策"说明差异，避免重复发表。

### 7.3 论文与项目的关系

论文不是额外工作，是从同一批实验里抽取。
仓库结构（Master + 实验注册表 + 计划版本链）已按项目一的模式建好，就是为了这件事。

## 8. 规范（沿用项目一）

1. 先预注册再运行；阈值与参数只用训练/验证场景确定，测试场景只开一次。
2. 证据等级 A/B/C/D；等级 C/D 不得写进摘要与结论。
3. 三层次报告：观察 / 解释 / 局限，绝不把解释写成观察。
4. 每个实验交付：结果、脚本、日志、CSV、图、初步理解。
5. 失败保留；每个数字可追溯到实验编号。
6. 计划版本由实验结果触发，不预写下一版内容。
