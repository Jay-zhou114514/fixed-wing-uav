# 版本更新模板

复制以下结构生成新版本。**不要在实验结果审查完成前填写内容。**

```markdown
# 固定翼无人机风扰下航迹可执行性研究计划 v<X.Y>

- Version：
- Update basis（本版依据的实验编号）：
- Current stage：
- Next experiment：
- Update principle：Experimental-result-driven iterative planning

## 1. 已确认事实
（只写有受控实验支持、且等级为 A/B 的内容，注明实验编号）

## 2. 被否定或弱化的假设
（原假设 / 被什么证据否定 / 弱化到什么程度）

## 3. 当前最可信机制
（最多 3 条，各标 A/B/C/D）

## 4. 当前最大科研风险
（场景数量与功效、独立性、多重比较、模型简化、泛化）

## 5. 下一实验及理由
- 实验编号：
- 可检验预测：
- 控制变量：
- 判据：

## 6. 论文 / 作品集故事如何随证据变化
（相对上一版，哪些表述必须修改或撤回）
```
