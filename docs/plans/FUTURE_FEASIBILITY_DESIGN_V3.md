## 1. 判断标准：什么算"验证项目"，什么算"研究项目"

这是 V2.0 设计的第一性依据。用可操作的方式定义：

| | 验证项目 | 研究项目 |
| --- | --- | --- |
| 产出物 | 通过 / 不通过 | **一个判据、一条法则、一个边界** |
| 提问方式 | "这个方法行不行？" | "在什么条件下成立？边界在哪？" |
| 结论的可否证性 | 弱（一次通过即结束） | 强（法则可被单个反例推翻） |
| 失败时的产出 | 接近零 | 仍是一个边界结论 |
| 同行评审关注点 | "你复现了别人" | "你给出了什么新量" |

**本仓库已有的模板**（这条最重要）：

EXP-FW-V1-23 的 `τL* = 1/(ω(1+w))` 之所以是研究级产出，因为它同时满足五条：

1. **精确**（闭式，非拟合）；
2. **无量纲**（`ω·τL* = 1/(1+w)` 弧度）；
3. **反直觉的参数无关性**（与空速 Va 完全无关）；
4. **有物理解释**（允许的航向损失角）；
5. **可被单个反例推翻**。

**V2.0 的检验标准**：能否为决策问题造出同级的第二块资产。
答案是能——见第 3 节。

## 3. V2.0 的核心研究级产物（候选判据）

### 3.1 判据（已核验）

设动作 a 的代价 `J(a)`（min）与未来可行空间 `F(a)`（max）。
取可达 (J, F) 点集，计算其**下凸包**。则：

```text
动作 a 不可被任何 λ ≥ 0 的惩罚型规则复现
    ⟺  a 被下凸包跳过（不在凸包顶点上）

推论 A：可达 (J,F) 集凸  ⟹  约束型 ≡ 惩罚型（任何 F_min）
推论 B：分歧区间 = 被跳过的 F_min 区间
```

**核验结果**（`notes/verify_frontier_criterion.py`）：

| 核验 | 方法 | 结果 |
| --- | --- | --- |
| 判据正确性 | 4000 组随机点集、6350 个 Pareto 点，判据 vs 暴力 λ 搜索 | **零不一致** |
| 平台差异 | 固定翼式离散集 vs 凸权衡集 | 离散集跳过 2/4 个 Pareto 点（有分歧）；凸集跳过 0/21（无分歧） |

**一次被判据本身推翻的尝试（保留记录）**：第一版判据写成"该点处前沿局部凹即可
不可支撑"。反例显示：某点局部凸，却被**远处一个边际代价极低的点**压低了 λ 上界，
故仍不可支撑。结论：**不可支撑是全局性质，必须用凸包成员判定，不能看局部斜率。**
这条否决记录保留，因为它决定了实现方式。

### 3.2 一个双刃的结果：混合会抹掉分歧

核验 2 显示（`F_min = 35`）：

| 决策模型 | 最优 (J, F) | 可支撑 |
| --- | --- | --- |
| 单动作承诺（本项目） | (4.0, 35.0) | **否** |
| 允许混合（随机化） | (2.69, 35.0) | 是 |

含义有两面：

- **作为机制洞察**：分歧要求"**确定性单动作承诺** + 非凸可达集"两者同时成立。
  任缺其一，约束型都退化为惩罚型。
- **作为审稿风险**：审稿人可主张"分歧只是因为你禁止了随机化"。

**对此的辩护（需在论文中写清，且需 G1 支撑）**：
F 对动作**不可加**——执行动作 A 得到 F(A)，执行 B 得到 F(B)，
但"执行 A 的 50% + B 的 50%"不是一个可实现的机动；(J, F) 的凸组合
不对应任何真实机动。因此可达集就是**已实现机动的集合**，凸包松弛在物理上不可达。
这一条必须论证，不能默认。

### 3.3 固定翼为什么提供非凸性（V2.0 的立论核心）

两个候选来源，**均待 G1 补文献证据或自行证明**：

1. **机动集的离散拓扑**：固定翼的机动由 Dubins 词（LSL/LSR/RSL/RSR/RLR/LRL）刻画，
   是**拓扑离散**的族，而非连续可调参数。离散点的下凸包必然跳过部分 Pareto 点。
2. **风致曲率的非单调**：EXP-FW-V1-02 已建立地面曲率式
   `κ_g = Va·ψ̇·(Va + W·e_ψ)/|Va·e_ψ + W|³`。随风向相对关系变化时，
   同等路径长度的未来可达集变化率非单调，从而在连续族上也产生凹区。

**多旋翼的对照**：机动集近似连续且凸（可悬停、可横移），
下凸包不跳过 Pareto 点 → 无分歧 → "换成四旋翼就不一样"成立（可检验）。

**诚实标注**：3.3 的两条来源目前是**假说**，证据等级 **C**。
来源 1 需要文献或证明；来源 2 需要 S1 平台的数值证认。**两者都是 G1/G4 的内容。**

### 3.4 必须声明的引用义务

"支撑点 / 非支撑点（supported vs unsupported efficient solutions）"是
多目标优化的**教科书内容**。因此：

- **不得**声称首次发现"非凸前沿导致惩罚法失效"；
- 必须在 G1 中补上该结论的**精确原始引用**（经典文献 + 近年综述各一），
  并明确本项目与之的差异；
- 本项目可主张的三点收窄为：
  (i) **固定翼机动集的非凸性是结构性的**（而非算例巧合）；
  (ii) **分歧区间的量化**（在什么 `F_min` / 什么几何下分歧，量级多大）；
  (iii) **对真实任务成功率的影响**（分歧是否真的改变结果，而非只是理论差异）。

### 4.1 其中三个需要特别说明

**EXP-FW-V1-37（凸性普查）是新增实验里最关键的。**
理由：由 3.1 推论 A，若场景的可达集近凸，约束型与惩罚型**必然**给出相同结果，
实验测出"无改善"——这是一个**无法解读的假阴性**（分不清机制不存在与算例太滑）。
因此必须先用普查确定非凸区存在，且把凸性指标作为**场景筛选条件**写进预注册。

**EXP-FW-V1-38（混合消融）是设计成"两种结果都可发表"的关键。**
两种结果都有意义：
- 混合后分歧消失 → 机制是"承诺不可逆"，论文讲这个（更深的结论）；
- 混合后分歧仍在 → 说明非凸性更强，论文讲这个。

**EXP-FW-V1-40（闭环演示）必须防挑选。**
大创展示需要"传统规划进死区失败 / 未来感知绕路成功"这类图。
但挑一个有利于自己方法的场景就是 post-hoc。
**规则**：演示用例必须由**预注册的选择规则**从验证场景中自动选出
（例如"选 A_myopic 失败率最高且 ΔF 最大的场景"），并同时报告该规则在全部场景上的命中率。

### 4.2 现有 S0–S6 的处置

不变，但插入依赖：**EXP-30 → EXP-37 → S2(EXP-32)** 是新的必经链。
`FROZEN_PROTOCOL.md` 第 8 节的非凸性验证条款由 EXP-37 执行。

### 5.1 可主张的三点（表述、依据、等级、风险）

| # | 创新点表述 | 依据 | 等级 | 主要风险 |
| --- | --- | --- | --- | --- |
| **1** | **机制**：提出"未来可行空间作为决策**约束**"的判据，并证明在固定翼非凸机动集下该约束**不可归约为代价惩罚**（存在判据与分歧区间） | 下凸包成员判据（已核验，零不一致） | B（判据）/ C（固定翼结构性） | 数学内核是教科书内容；必须引用而非声称 |
| **2** | **量化**：给出分歧区间随固定翼几何参数（转弯率 ω、风速比 w、机动词表）的**解析预言**，与 `τL*` 同级的闭式刻画 | 待 EXP-39 | 未定 | 若解析预言做不出，降级为数值相图 |

### 5.2 不能主张的（写进申报书的"研究边界"段）

1. **不得**声称首次提出"未来可行性"、"可达性约束决策"、
   "选项保留"——这些概念可能在 reachability / viability / backup-plan /
   contingency 名下已存在（G1 未完成，尚不能断言）。
2. **不得**声称首次发现"非凸前沿使惩罚法失效"——多目标优化教科书内容。
3. **不得**声称跨平台普适——本项目恰恰主张平台特异，这是优点不是缺点，但要说清。
4. **不得**把 H2（判据）写成 A 级——目前只在**构造算例**上核验，
   **尚未在真实固定翼场景测量**（这正是 EXP-37/39 的任务）。

### 5.3 一句话版本（供申报书摘要与答辩开场）

> 固定翼无人机的机动集是**拓扑离散**的（Dubins 词），因此"执行哪个动作"
> 会改变未来还剩下多少可行空间。本项目证明：当可达代价–可行空间集合非凸时，
> 把这个空间作为**约束**来选动作，**无法**被任何"给代价加惩罚项"的做法复现；
> 并给出分歧区间随固定翼几何参数的解析刻画。

**讲给评委的版本**（更短）：

> 传统决策只问"这一步划不划算"。我们问"这一步之后，还有没有路可走"。
> 对固定翼来说，这两个问题的答案**可以不一样**，而且我们能算出什么时候不一样。

## 6. 会议论文路线

### 6.1 论文一（会议线，目标 2027-03 投稿）

**标题方向**：固定翼未来可行性约束决策的**不可归约性与分歧边界**

| 贡献 | 依赖实验 | 不可替代的证据 |
| --- | --- | --- |
| C1 判据：约束型 ≠ 惩罚型的可判定条件 | EXP-37/38 | 凸性普查 + 混合消融 |
| C2 边界：分歧区间随 ω、w、词表的解析刻画 | EXP-39 | 解析预言 vs 数值 |
| C3 影响：分歧是否改变真实任务结果 | EXP-40/42 | 闭环成功率 + MPC 对照 |

**关键路径**（倒推）：

```text
2027-03 投稿
  ← 2027-02 论文定稿（需要 C1+C2+C3 齐备）
  ← 2027-01 EXP-39（解析预言）+ EXP-42（MPC 对照）
  ← 2026-12 EXP-37（凸性普查）+ EXP-38（混合消融）
  ← 2026-11 EXP-30 完成 + S1 平台完成
  ← 2026-10 G1 完成（≥15 篇全文）
```

**风险**：若 G1 发现判据已被占据，则 C1 降级为引用，论文卖点移到 C2+C3
（量化与影响），仍可成立——这已由第 5.1 节的三点收窄保证。

### 6.2 论文二 / 期刊线（2027-07 起）

在论文一基础上加三块（**不预写内容，仅登记**）：

- **不确定性调制**（EXP-41）：什么风/估计误差下 F 才有价值；
- **计算延迟耦合**：用 `τL*` 作为"F 约束下还允许算多久"的预算
  （这是把第一根支柱与第二根支柱接起来的地方，也是最有想象空间的扩展）；
- **分布外泛化** + 与管式 MPC / CBF 安全层的深入对照。

目标期刊：Drones（本子领域主场）、Aerospace、IEEE Access。

### 6.3 兜底：四种结果都有出路

| 结果 | 论文形态 |
| --- | --- |
| 判据成立且分歧在真实场景出现 | 发现型：不可归约性 + 边界 + 影响（主路径） |
| 判据成立但真实场景分歧稀少 | **边界型**：给出"何时不出现分歧"的条件（仍是有效结论） |
| 混合后分歧消失 | **机制型**：结论变为"分歧来自承诺不可逆"（更深的结论） |
| 判据在真实场景不成立 | **负结果型**：判据的适用边界 + 可复现平台 |

**没有一种结果是零产出**——这是沿用 v1.2 第 7 节的设计原则。
