## 3. 核心假设（冻结）

### 3.1 H-core

> **该围栏构造在"瞬时转弯"理想模型下恰好充分（垂直风向余量为 0），
> 因此在真实滚转动力学下必然不足；不足量等价于一个滚转时间常数的延迟。**

### 3.2 三个子预测（可分别被单个反例推翻）

| 编号 | 预测 | 可证伪条件 |
| --- | --- | --- |
| **H1** | 方向上：临界延迟 `τ_crit(n) = margin(n) / (Va + W·n)`。沿风向 = `1/(ω(1+w))`；**垂直风向 = 0** | 若在 n ⊥ W 方向测得 τ_crit > 0 且非噪声 → H1 假 |
| **H2** | 空速无关性：沿风向的 τ_crit 不随 Va 变化 | 若 τ_crit 随 Va 单调变 → H2 假（K1 也受损） |
| **H3** | **滚转滞后修正**：真实滚转动力学下 `τ_crit(实际) = τL* − τ_roll`；在 n ⊥ W 方向为 `−τ_roll < 0`（**即零延迟也不足**） | 若实测修正量 ≠ τ_roll（偏离过大）→ H3 假 |

### 3.3 H1 与 H3 的推导与验证状态

**H1 的推导**：延迟期间飞机以地速沿 n 前进，消耗裕度 `margin(n)`；
消耗速率 = `v·n = Va·cos∠(航向,n) + W·n`。迎面接近时 = `Va + W·n`。
故 `τ_crit(n) = margin(n)/(Va + W·n)`。在 n∥W 处退化为 EXP-23 的 `1/(ω(1+w))`。

**H3 的推导**：一阶滚转响应 `φ(t)/φ_max = 1 − e^{−t/τ_roll}` ⟹
转弯角速率 `ω_eff(t) = ω(1 − e^{−t/τ_roll})` ⟹

```text
航向角亏损 = ∫₀^∞ [ω − ω_eff(t)] dt = ω · τ_roll
等价延迟   = 航向亏损 / ω = τ_roll
```

**已验证**（数值积分 vs 解析式）：τ_roll ∈ {0.3, 0.5, 0.8, 1.2} s 上相对偏差
**8.33e-10**（纯数值误差）。

**H1/H3 的数值一览**（Va = 18 m/s，ω = 25°/s，R = 41.2530 m）：

| w | τL*（理想） | τ_roll = 0.3 | 0.5 | 0.8 |
| --- | --- | --- | --- | --- |
| 0.1 | 2.0835 s | 1.7835 | 1.5835 | 1.2835 |
| 0.3 | 1.7629 s | 1.4629 | 1.2629 | 0.9629 |
| 0.5 | 1.5279 s | 1.2279 | 1.0279 | 0.7279 |
| **n ⊥ W** | **0** | **−0.3** | **−0.5** | **−0.8** |

**状态：H1 与 H3 目前均为等级 C（推导 + 数值自洽，但未经闭环检验）。**
**不得写入任何摘要或结论。**

### 3.4 必须主动排除的替代解释

## 4. 主实验：EXP-26 重新设计（冻结规格）

### 4.1 为什么它是主实验

由潜力评估：本项目最大的风险不是被抢先，而是**"数学精确但工程无关"**。
EXP-26 是唯一能把几何量翻成**任务层后果**的实验：

- 它把 `τL*` 从"一个秒数"变成"**越界率随延迟的边界**"；
- 它检验 K2/K3 的方向结构是否有**任务层对应物**；
- 它检验 H3——若成立，则给出**该构造在真实动力学下不足**的定量结论，
  这比"验证充分"有分量得多。

### 4.2 研究问题

> 该围栏构造的安全裕度方向结构，在闭环系统中是否表现为
> "允许接管延迟随接近方向变化、且在垂直风向方向为零"的**任务层边界**？

### 4.3 设计

**场景**：单条直线围栏边（消除顶点干扰；顶点情形见 4.8 的前置检查）。
按 JAIS 第 III.B 节生成缩放层（警告层），距原始边界 δu。

**被控对象**：3-DOF 水平面点质量；常值空速 Va；最大转弯角速率 ω；常值风 W（沿 +x）。

**控制律（两臂）**：

- **臂 I（理想）**：触发后**瞬时**以 ω 转弯（无滚转滞后）。
  预言：几何量应**精确**复现（H1）。
- **臂 R（真实）**：触发后滚转一阶响应，时间常数 τ_roll。
  预言：`τ_crit = τL* − τ_roll`（H3）。

**触发条件（冻结）**：飞机航迹点到达**警告层**（距原始边界 δu）时开始计延迟 τ；
τ 之后接管控制器以最大速率转向背离围栏方向（方向由"最小转弯圆不相交"规则定，
沿用 Thomas 2024 的思路但**不采用其经验 `s_t`**）。

**自变量**：

| 变量 | 取值 |
| --- | --- |
| 接近方向角 φ_approach（相对风向） | 0°, 30°, 45°, 60°, 90°, 120°, 135°, 180°（+ 对称侧） |
| 接管延迟 τ | 0 … 1.5·τL*，步长 0.05 s（关键区加密） |
| 风速比 w | 0.1, 0.3, 0.5 |
| 空速 Va | 15, 18, 25 m/s（检验 H2 与 K1 的空速无关性） |
| τ_roll（臂 R） | 0.3, 0.5, 0.8 s |

**因变量**：

1. **是否越界**（二值，穿越原始围栏边界）；
2. **越界深度**（m，越过边界的最大距离）；
3. **实测临界延迟** `τ_crit^meas`（越界与否的转变点，二分细化）。

### 4.4 判据（预先写定）

| 编号 | 判据 | 通过条件 |
| --- | --- | --- |
| **P1** | 臂 I 的 `τ_crit^meas(φ)` 与 `margin(φ)/(Va + W·n)` 一致 | 相对偏差 < 1e-3（除零容忍方向） |
| **P2** | 臂 I 在 φ = 90°（n ⊥ W）时 `τ_crit^meas = 0`（精确） | 绝对偏差 < 1e-6 s |
| **P3** | 臂 I 的 `τ_crit^meas` **与 Va 无关** | 同一 w、同一 φ 下跨 Va 的变异系数 < 1e-3 |
| **P4** | 臂 R 的 `τ_crit^meas = τL* − τ_roll` | 相对偏差 < 5%（允许有限瞬态近似） |
| **P5** | 臂 R 在 φ = 90° 时**即使 τ = 0 也越界** | 越界发生 |
| P6 | 越界深度随 τ − τ_crit 线性增长（失效侧） | 线性拟合 R² > 0.99 |

**判定**：

- **支持 H1+H2+H3**：P1–P5 全通过 → 项目升级为**发现型**论文
  （方向依赖预算 + 真实动力学下的不足量与修正）。
- **部分支持**：P1–P3 通过但 P4 不通过 → H3 假，退回"理想模型下的方向结构"，
  仍可发表（边界型）。
- **不支持**：P2 或 P3 失败 → 方向结构无任务层对应物，
  项目降级为"优秀大创 + 负结果报告"（`V2_DESIGN.md` 6.3 的兜底形态）。

### 4.5 为何不需要功效分析（须在预注册中显式声明）

臂 I 与臂 R 均为**确定性**系统（给定初始条件与参数，无随机源），
因此本实验是**阈值预测的精确核验**，不是统计推断。
按 `CONVENTIONS.md` 第 7 节，功效分析仅对统计主张必需。

**但**：若后续版本引入随机源（风估计误差、传感器噪声、初始条件分布），
**必须**先做功效分析。该约束写死于本文件。

### 4.6 与"同义反复"风险的正面处理（最重要的一条）

**风险**：EXP-26 可能只是把 EXP-21/27 的几何重新算一遍，因此"必然通过"，
不构成独立验证。（同类风险曾在 `LATENCY_FAILURE_SIDE_NOTE.md` 第 0 节记录过。）

**本设计的防线**（三点，缺一则重做）：

1. **臂 I 必须从控制律独立实现**——不得调用 EXP-27 的 `required()` 函数；
   只允许调用运动学积分与围栏几何。
2. **触发机制是新增物理**：EXP-27 对 `required(n)` 取**对抗性最优**的初始航向 psi0；
   EXP-26 的触发由**接近几何决定**初始航向。两者只有在轨迹确实到达警告层时才一致。
3. **H3 与 H1 不是同义反复**：H3 引入一阶滚转动力学，
   其修正量 `τ_roll` **不来自**任何已有几何计算（3.3 节的推导是独立的）。
   **H3 是本实验真正的新内容。**

#### EXP-FW-V1-27A 的精确陈述（本次冻结新发现）

EXP-27 的 P2 检查的是**逐边独立**条件：

```text
对每条边 e：given(n_e) ≥ required(n_e)，其中 required(n_e) = max_{psi0} min_{sign} max_t d_{sign}·n_e
```

即**每条边各自允许选择最有利的转弯方向 `sign`**。

但闭环安全要求的是**同时**满足所有边：

```text
对每个 psi0，存在**单一** sign，使得对所有边 e：max_t d_sign(t;psi0)·n_e ≤ given(n_e)
```

**若不同边的最优 sign 不同，逐边检查不足以保证同时条件。**
即 EXP-27 的 P2 是**必要但不显然充分**的。

这条缺口**与凹多边形无关**，在凸多边形的**顶点附近**可能出现
（迎角接近顶点时，一个转弯方向躲开一条边却进入另一条边）。
**成本极低**（纯几何重算，无需新物理），**且可能比 27B 更早暴露问题**，
故列为 EXP-26 的第一前置。

**注意**：本条**不构成对 EXP-27 结论的反驳**——
EXP-27 的 K2/K3/K4 是对"逐边安全裕度"的陈述，该陈述本身成立；
本条指出的是"逐边 ⇒ 同时"这一步未经检验。

## 6. 大创叙事（冻结版本）

### 6.1 一句话

> 无人机电子围栏要往外扩一圈才安全。已有的扩法只被检查过"形状合不合法"，
> 没被检查过"够不够用"。我们补上这个检查，并算出两条设计公式：
> **围栏能给飞控留多少反应时间，只取决于飞机转得多快、风有多大——与飞多快无关**；
> 而且它在垂直于风向的方向上**一点余量都没有**，
> 一旦考虑真实的滚转滞后，那个方向**即使零延迟也不足**。

### 6.2 为什么这是好大创（不靠算法堆砌）

| 要素 | 本项目 |
| --- | --- |
| 对象 | 一个具体、已发表的航空方法（JAIS 2020），非泛泛"智能决策" |
| 问题 | 可一句话说清、可被单个反例推翻 |
| 证据 | 等级 A 的精确法则；预注册；失败与撤回留档 |
| 展示 | 裕度-方向图、越界率-延迟图（EXP-26 产出） |
| 能力证明 | 规范（预注册/证据等级/三层次报告）+ 可复现平台 + 自查纠错 |

### 6.3 必须对评委讲清的边界（讲清楚反而加分）

1. 方法不是我们发明的——解析缓冲 + 充分性证明是既有传统，我们做的是**具体构造的精确刻画**；
2. "延迟预算"概念 Thomas 2024 已提出——我们给出的是**精确闭式、含风、与空速无关**的版本；
3. 有一篇 Kim 2022 摘要自称做过类似验证，**我们尚未拿到全文**，
   因此表述限定为"该构造未被检验"。

**这三条写进申报书，是成熟度的证明，不是弱点。**
