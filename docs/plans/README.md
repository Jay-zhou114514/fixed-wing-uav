# 计划目录

计划是唯一真相源。**每次重要实验完成后发布新版本，不预先写下一版。**

## 1. 规则

1. **不预写下一版**。版本由实验结果触发。
2. 每次更新必须写明：新增证据、被推翻的假设、保留路线、淘汰路线、下一轮实验及理由。
3. 最终题目由证据链决定，不由申报书倒推。
4. **每个结论级实验结果，必须先在"实验→计划变更"追踪表登记**（见 `RESEARCH_PLAN_v1.4.md` 第二节），
   未登记者不得进入论文。
5. 计划版本升级必须能追溯到追踪表的某一行。

## 2. 每个版本必须回答的六要素（对齐项目一 motor）

| # | 要素 | 说明 |
| --- | --- | --- |
| 1 | **已确认事实** | 哪些结论已有实验支持（须标证据等级 A–D） |
| 2 | **被否定或弱化的假设** | 哪些解释已被证伪或必须降级 |
| 3 | **当前最可信机制** | 现阶段证据最支持什么（≤3 条，各标等级） |
| 4 | **当前最大科研风险** | 审稿人最可能质疑什么 |
| 5 | **下一实验及理由** | 为什么做这个，而不只是"做什么" |
| 6 | **论文故事版本** | 当前证据下论文该如何表述 |
