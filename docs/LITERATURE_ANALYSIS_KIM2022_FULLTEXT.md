## 1. 它做了什么

| 项 | 内容 |
| --- | --- |
| 问题 | **缓冲需要多大**（volume sizing） |
| 对象 | 包裹**一条已知标称航迹**的管状 keep-in 围栏（体积化） |
| 保证形式 | **统计**：位置标准差 × 3，即 **99.7% 置信** |
| 缓冲构成 | 导航不确定度（3σ） + 制导误差 + **机体尺寸**（半机身长/翼展/机高） |
| 缓冲形状 | **各向同性**：横截面取横/垂向两者最大，原文称截面为 "square" |
| 顶点/内角 | **不处理** |
| 接管延迟 | **不处理** |
| "转弯飞行" | 仅通过 **σ 的数值**体现（转弯增大跟踪误差 → σ 增大），**无转弯专用几何项** |
| 模型精度 | 6-DOF + 非线性气动（含失速）+ 舵机饱和 + CFD 城市风场 |

**与本项目的关系**：其参考文献 [6] 即 **Stevens & Atkins, JAIS 2020**——
**正是本项目的研究对象**。故该文与本项目**同出一个课题组传统**（Atkins）。

## 2. 对比表（本记录的核心）

| 维度 | Kim 2022 | 本项目 |
| --- | --- | --- |
| 问题 | **缓冲需要多大**（size） | **既有缓冲的裕度如何变化**（margin） |
| 对象构造 | 自有的航迹包裹体积 | **JAIS 2020 的 δu⊕δd 多边形缩放** |
| 保证形式 | 统计（3σ） | 解析（闭式 `R·cos(θ/2)`、`R·cot(θ/2)`） |
| 缓冲形状 | **各向同性**（截面方形） | **方向依赖**（K2：沿风 δu / 垂直风 0） |
| 顶点/拐角 | 不处理 | **K8 / K9** |
| 接管延迟 | 不处理 | **K1 / H2 / H3** |
| 动力学 | 6-DOF（更精细） | 3-DOF 点质量（更简，可解析） |

**结论**：问题层面、方法层面、构造层面**均不同**，
本项目核心结论 **K1/K2/K8/K9/H2/H3 均不被其覆盖**；
该文只做**尺寸设计**，不做**给定缓冲下的裕度刻画**。

## 3. 由此修正的项目定位（对比的直接产物）

| 项 | 处置 |
| --- | --- |
| **K6 / D1**（"裕度特性尚不清晰"） | **维持**：该文只做尺寸，不做裕度；固定表述继续适用。支撑由摘要升级为全文（该文全部案例均为缓冲尺寸数值） |
| **D18**（"此前工作未考虑转弯"） | **维持删除**，理由加强：其 σ 确实内含转弯飞行影响 |
| **D19（新增）** | **不得**声称"既有围栏缓冲忽略方向依赖/假设各向同性"——JAIS 2020 本身即用**方向性** δd；Kim 的各向同性是其**问题设定**（包裹一条已知航迹）使然，取 max 属**保守**选择。两者是**不同设计哲学**，**不作优劣判断** |
| **R2 风险** | 由"中等偏低"上调为**中等**：同课题组持续在"缓冲尺寸 + 不确定性 + 风"上产出，其未来工作直言要建"不同城市模型/风况的缓冲尺寸数据库" |
| 论文写法 | Related Work 中与该文**并列对照**：它 = 统计式缓冲尺寸设计（3σ，各向同性截面）；本项目 = 解析式裕度刻画（方向依赖）。**不作优劣判断** |

**缓解措施**：卖点固定在**解析闭式（K8/K9）+ 顶点/延迟（K1/H2/H3）**，
即该课题组明确不做的部分；不依赖泛泛的"裕度刻画"。
