# 在实验中找创新点的策略

日期：2026-09-16
依据：`experimental-design`（实验设计）+ `research-state`（研究状态）+ `research-stack-router`（相位与断言强度）

## 0. 核心判断

在这个领域"想"不出新点，是因为可想的点都被做完了。**创新点只能从"文献的预期"和"实验的实测"之间的差里来。**

所以流程必须是：

```text
文献预期 → 把它变成可检验预测 → 用筛查实验快速找差 → 归因 → 机制 → 泛化 → 最小修复
```

这也正是原 V0.1 计划里的"阶段 2 压力测试 → 阶段 3 从异常现象中找问题"，
只是要把它做成**有统计效力的实验**，而不是随手跑几个场景。

## 1. 第一步：把文献主张变成可检验预测

产出物叫**预测卡**，每张卡包含四项：

| 字段 | 内容 |
| --- | --- |
| 主张 | 原文说了什么（引用 + 页码） |
| 条件 | 在什么条件下成立 |
| 预测 | 如果是真的，我的实验里必须观察到什么（可量化） |
| 证伪 | 观察到什么就说明它不成立 |

要求：从 15–20 篇近三年论文里，每篇抽 1–3 张卡，合计 30–50 张。
**这一步必须读正文**，靠标题和摘要是抽不出预测卡的。

典型预测卡示例：

- 主张：某风感知规划器在城市风场下成功率显著高于常半径基线。
- 条件：中高风速、障碍密集。
- 预测：在统一协议下，相对成功率提升 ≥ 20 个百分点，且跨 5 个随机种子稳定。
- 证伪：提升 < 10 个百分点，或提升只在部分种子下出现。

## 2. 第二步：用筛查设计找差

**为什么是筛查设计**：候选因子有 5–8 个，全因子要 2^7 = 128 组，成本高。
Plackett–Burman 或低分辨率分数因子只需 8–12 组就能估出各因子的**主效应**，
先用它找出"哪个因子让预测失效"，再对少数因子做精细实验。

本项目候选因子（每个二水平）：

| # | 因子 | 低 | 高 |
| --- | --- | --- | --- |
| 1 | 风速比 w | 0.10 | 0.35 |
| 2 | 风向相对转弯方向 | 顺风 | 逆风 |
| 3 | 障碍密度 | 低 | 高 |
| 4 | 障碍尺度 / R_a | 0.5 | 2.0 |
| 5 | 规划安全裕度 | 0.25 R_a | 1.0 R_a |
| 6 | 规划器族 | 常半径几何 | 风感知几何 |
| 7 | 转弯方向序列 | 连续同向 | 交替 |

筛查的产出不是"谁更好"，而是"哪一个因子显著改变了我关心的量"。

## 3. 第三个关键设计决定：独立重复的单位是什么

这是 `experimental-design` 里最重要的一条，也是这类研究最常见的致命错误——
**伪重复（pseudoreplication）**。

在仿真研究里，真正的独立重复**不是**单个场景。同一场景族（同一套障碍拓扑、
同一组生成参数的邻域）里生成的 100 个场景是相关的，它们共享生成器参数。
把 100 个相关场景当成 100 个独立样本，就是在伪造统计效力。

正确处理：

- **场景族作为区组（block）**：同一族内比较不同方法，把族间差异从误差项里拿掉。
- 风与安全裕度在族内**随机化**。
- 每个格子跑 ≥ 3 个随机种子，种子也是重复层级。
- 分析用混合模型或分层聚合，不要把场景当独立样本。

## 4. 第四步：深度阶梯（如何深入实验）

从浅到深五级，每级有出口条件，过了才进下一级。

| 级 | 做什么 | 出口条件 |
| --- | --- | --- |
| L1 现象 | 在统一协议下测，看差存不存在 | 差可重复，跨种子稳定 |
| L2 归因 | 受控干预：一次只改一个因子，做全因子或配对比较；分离主效应与交互 | 能指出是哪个因子造成差，且排除了主要替代解释 |
| L3 机制 | 给出解析预言（像地面曲率公式那样），再用数值仿真独立验证 | 预言与仿真一致（相对误差 < 1e-3），且预言能被证伪 |
| L4 泛化 | 分布外场景族、参数外推、跨风速区间、功效分析 | 结论在训练条件外仍成立；报告效应量与置信区间 |
| L5 修复 | 最小改动的方法，加消融 | 修复有效，且代价（路径长度/时间）有界 |

**判据**：能不能写出一条"如果我的解释是对的，那么 X 必须成立"的预言。写不出来，说明还停在 L1。

另外三条深度要求：

1. 从平均到分布：报均值、方差、置信区间、最坏情况，不只报最好一次。
2. 从能跑到能复现：种子、脚本、日志、CSV、图齐全（这是 Motor 的老规矩）。
3. 保留失败：负结果是结果。

## 5. 设计成"两种结果都可发表"

拥挤领域里最重要的一条策略：**不要设计只有一种结果才成立的实验。**

以"安全记账误差审计"为例：

- 若发现偏差显著 → 论文是"现有风感知规划在安全记账上系统性偏差，给出机制与最小修复"。
- 若发现偏差不显著 → 论文是"在统一协议下检验了该领域的安全声明，未发现偏差，并给出可复现基准与适用边界"。

两种都是可发表的结果。反过来，如果项目设计成"只有我的方法赢了才成立"，失败就等于零产出。

## 6. 推荐的第一个实验（可立刻开工）

**EXP-FW-V1-03：统一协议下的安全记账审计**

- 单位：一次 (规划器 × 场景 × 种子) 运行。
- 区组：场景族。
- 响应：Δ = 规划器预测的最小障碍间隙 − 实际地面航迹的最小间隙；以及假安全率（Δ < 0 的比例）。
- 因子：见第 2 节七因子。
- 阶段一：Plackett–Burman 筛查（8–12 组），找出主导因子。
- 阶段二：对主导的三因子做 2³ 全因子 + 区组。
- 前置：先做功效分析，确定族数与种子数（Motor 的教训：功效不足会让阴性结果无法解释）。
- 计划器：先只用几何规划器（常半径 Dubins、航向格 A*、风感知变体），
  RL 策略放到第二阶段，避免算力与不稳定性拖住进度。

## 7. 三个必防的结构性错误

1. **伪重复**：见第 3 节。这是本领域最可能踩的坑。
2. **混杂**：方法比方法时，别让"谁的参数调得更狠"混进来。给所有方法同样的调参预算。
3. **功效不足**：先算再跑。跑完才发现功效不够，只能写"无法判定"。

## 8. 决策门

| 门 | 条件 | 动作 |
| --- | --- | --- |
| G1 | 预测卡 ≥ 30 张，且有 ≥ 3 张能在 L1 快速检验 | 进入筛查实验 |
| G2 | 筛查找出 ≥ 1 个主导因子，且效应跨种子稳定 | 进入归因 |
| G3 | 归因能排除主要替代解释 | 进入机制 |
| G4 | 机制有解析预言且通过独立验证 | 进入泛化 |
| G5 | 泛化成立，功效充足 | 进入修复，并在同时写会议论文 |

任一门未过，回到上一级，不靠堆实验硬推。
