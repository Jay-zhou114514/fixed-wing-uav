# fixed-wing-uav

**风扰下固定翼无人机围栏缓冲构造的精确适用边界。**

这是一个本科研究项目（大创项目二）。研究对象是一个具体、已发表的方法，不是"智能决策"这类宽泛方向。

## 这个项目在问什么

Stevens 与 Atkins (2020, *Journal of Aerospace Information Systems*, doi:10.2514/1.I010792)
给出了固定翼无人机电子围栏的缓冲距离算法：均匀缓冲 δu = 转弯半径，
方向缓冲 δd 随风速变化、方向取风向。

**该文给出了缓冲数值的推导，但从未验证过这些数值是否足以防止飞机在有风条件下越界。**
它的蒙特卡洛（3×10⁶ 个随机多边形）验证的是"算法能否为随机多边形生成合法分层"，
是一个几何可行性指标，不是安全性指标。

本项目补上这个缺失的验证，并刻画这个构造在哪里成立、余量有多少、
以及余量会被哪些现实因素吃掉。

## 目前确立的结果

| 结论 | 数值 | 证据等级 | 实验编号 |
| --- | --- | --- | --- |
| 论文的 δd 是**精确**的最坏穿透量，不是近似 | 全风速区间相对偏差 0.0000 | B | EXP-FW-V1-21 |
| 缓冲构造在常值风下充分，无缺口 | 最大缺口 0.000 m | B | EXP-FW-V1-21 |
| 构造的余量**恒等于一个转弯半径**，与风速无关 | 余量 41.25 m，w = 0.1–0.5 不变 | B | EXP-FW-V1-22 |
| 静风时余量为零（δu 恰为精确最小缓冲） | margin = 0 | B | EXP-FW-V1-22 |
| 临界接管响应延迟 | **1.6–2.1 s**（w = 0.1–0.5） | B | EXP-FW-V1-22 |
| 延迟预算的设计规则 | 允许延迟 ≈ 转弯半径 / 顺风地速 | B | EXP-FW-V1-22 |

证据等级沿用项目一规范：B = 与现有证据一致，需进一步确认（尚缺参数稳健性与外部验证）。

## 一次被撤回的结论（保留记录）

EXP-FW-V1-20 曾报告"临界风速比 w\* ≈ 0.32，超过后缓冲不足"。
该结论在 EXP-FW-V1-21 中被**撤回**：原因是 EXP-V1-20 把机动时长设为一个完整转弯周期，
等于允许飞机在转向逆风后继续转回顺风被风推着走；真实接管控制器不会这样做。
修正判据后缺口消失。

实验记录与错误过程保留在文件中，未删除。

## 复现

```powershell
python -m pip install -r requirements.txt
python src/exp_fw_v1_21_corrected.py   # 缓冲充分性（修正判据）
python src/exp_fw_v1_22_latency.py     # 接管延迟对余量的消耗
```

两个脚本都会自检：无风时所需缓冲必须恰好等于转弯半径。

## 与项目一的关系

项目一 `motor-health-monitor` 提供方法规范：预注册、训练集独立选参、
证据等级 A–D、三层次报告（观察 / 解释 / 局限）、失败保留、版本化计划。
本项目沿用同一套规范，研究对象从振动信号换成固定翼运动几何。

## 诚实说明

- 全部为 3 自由度水平面点质量仿真；未含高度、气动、失速。
- 常值风；阵风、风切变、风估计误差尚未处理。
- 单一参数点（空速 18 m/s，最大转弯率 25°/s）；参数稳健性尚未验证。
- **本文档不主张该论文有误。** 我们检验的是一个重建的构造，结论是"未验证"而非"错误"。
