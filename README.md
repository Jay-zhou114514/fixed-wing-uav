# fixed-wing-uav

**固定翼无人机未来可行性驱动的自主决策 —— 计划 v1.2。**

这是一个本科研究项目（大创项目二）。当前处于 **Phase 0：文献定界与平台搭建**。

## 当前主线在问什么

> 在固定翼的非完整、不可悬停动力学下，两个"当前都安全"的动作，
> 是否会导致显著不同的**未来任务可行空间**？把这个空间用作决策**约束**
> （而不是给代价加一项目标函数），能否改变被选动作并提升任务成功率？

立项逻辑是"已有研究 A + 已有研究 B → 缺失连接"：

| 已有研究 | 它建立了什么 | 它没有建立什么 |
| --- | --- | --- |
| Reachability / Viability 理论 | `state → future possibility` | **动作之间的比较**（哪个动作创造更大的未来自由度） |
| 固定翼运动规划 | Dubins、最小转弯半径、风下闭式解 | 未来可行空间**作为决策准则** |
| **缺失连接** | — | **`action → future feasible set change`** |

**必须明确**：Reachability、viability、contingency planning、backup-plan feasibility
都是**既有**概念。本项目的可能增量在"动作层比较 + 约束型决策 + 固定翼特异性"三点，
且**尚未经文献审计确认**（G1 未通过，全文阅读量为 0）。在 G1 通过前不声称任何新颖性。

## 为什么现在改主线（v1.1 → v1.2）

v1.1 的主线是"地面系安全记账审计 Δ"。它**未被证伪，只是未被选择**——
编号保留、不复用、不作废，作为 v1.2 若失败时的回退方案。

v1.2 的技术立足点来自一次数学核验（`notes/CHAIN_C_THEORY_NOTE.md`）：

| 情形 | 约束最优 `argmin J s.t. F ≥ F_min` 能否被某个 λ 的惩罚项复现 |
| --- | --- |
| 固定翼式**离散热机动集**（非凸权衡） | **不能**（约束最优点"非支撑"，无任何 λ ≥ 0 支持它） |
| 类多旋翼**凸权衡集** | **能**（λ ∈ (1.19, 1.21)，101/101 全部可支撑） |

含义：固定翼的机动集天然非凸，所以"按未来可行空间约束选动作"**在数学上不等于**
"给代价加一项惩罚"——这是"换成四旋翼就不成立"的技术挡板。
**但它目前只是有限算例（证据等级 C），不是一般性定理。**

## 一个重要的方法论后果

由上面的核验直接推出（见 `FROZEN_PROTOCOL.md` 第 8 节，门控 G4）：

> **若实验场景使权衡集近似凸，约束型与惩罚型会给出相同结果，
> 实验必然测出"future-aware 无改善"，得到无法解读的假阴性。**

因此任何比较实验之前，**必须先报告场景的权衡集凸性指标**，确认存在非凸区域。

## 一次被撤回的结论（保留记录）

- **EXP-FW-V1-20** 曾报告"临界风速比 w\* ≈ 0.32，超过后缓冲不足"。
  该结论在 EXP-FW-V1-21 中被**撤回**：EXP-V1-20 把机动时长设为一个完整转弯周期，
  等于允许飞机转回顺风被风推着走；真实接管控制器不会这样做。修正判据后缺口消失。
- **`docs/LITERATURE_AUDIT_2026-09.md` 第 3 节**曾断言"若 F_future 是当前状态的函数
  则最优策略不变"。该断言**错误**，已撤回（只有势函数差分形式才保持策略不变），
  更正见 `notes/CHAIN_C_THEORY_NOTE.md`。

两次错误的过程与更正都保留在文件中，未删除——这是本项目规范的一部分
（见 `docs/CONVENTIONS.md` 第 5 节"失败保留"）。

## 复现

```powershell
python -m pip install -r requirements.txt
python src/exp_fw_v1_21_corrected.py   # 缓冲充分性（修正判据）
python src/exp_fw_v1_22_latency.py     # 接管延迟对余量的消耗
python src/exp_fw_v1_23_robustness.py  # 参数稳健性与精确延迟法则
python notes/verify_chainC_theory.py   # 约束型 vs 惩罚型的数学核验
```

三个实验脚本都会自检：无风时所需缓冲必须恰好等于转弯半径。

### 延迟预算法则

```text
tau_L* = 1 / ( omega * (1 + w) )       omega: 最大转弯角速率  w: 风速比
```

等价地，允许的航向损失角为 `1/(1+w)` 弧度（约 57.3°/(1+w)）。
