# fixed-wing-uav

**风扰与控制不确定条件下固定翼无人机电子围栏的安全裕度。**

这是一个本科研究项目（大创项目二）。研究对象是一个具体、已发表的航空方法。

## 这个项目在问什么

Stevens 与 Atkins (2020, *Journal of Aerospace Information Systems*, doi:10.2514/1.I010792)
给出了固定翼无人机电子围栏的缓冲距离算法：均匀缓冲 δu = 转弯半径，
方向缓冲 δd 随风速变化、方向取风向。

**该文给出了缓冲数值的推导与分层构造，但从未验证这些数值是否足以防止飞机在有风条件下越界。**
它的蒙特卡洛验证的是"算法能否为随机多边形生成合法分层"（几何可行性），不是安全性。
（已由本项目核对该文全文确认：全文 0 次 `guarantee`、0 次 `delay`、0 次 `uncertainty`。）

本项目补上这个检验，并把"够不够"量化为可用的设计数。

## 目前确立的两件研究级结果（等级 A）

### 1. 安全裕度具有确定的方向结构（EXP-FW-V1-27）

```text
margin(沿风向)  = δu = R      与风速无关
margin(垂直风向) = 0           精确紧
```

- 零裕度方向由"**边法线 ⊥ 风向**"决定，**与多边形形状复杂度无关**；
- 该构造**在最坏方向上零冗余**，因此任何未建模效应（延迟、风估计误差、
  跟踪误差）都会直接产生缺口；
- 三个自检全通过；125 个凸多边形构型 × 3 个风速比。
- **仅限凸多边形**；凹多边形与顶点展平未测（登记为 EXP-FW-V1-27B）。

### 2. 接管延迟预算的精确法则（EXP-FW-V1-23）

```text
τL* = 1 / (ω · (1 + w))        ω: 最大转弯角速率   w: 风速比
```

等价地，允许的**航向损失角**为 `1/(1+w)` 弧度（约 57.3°/(1+w)）。

**关键在于它与空速完全无关**——延迟预算只由转弯能力与风速决定，
可以在设计阶段直接算出来。45 点网格偏差 0.000。

其他已验证结果：

| 结论 | 数值 | 等级 | 实验 |
| --- | --- | --- | --- |
| 缓冲构造在常值风下充分（凸多边形） | 最小裕度 = 0（精确紧） | A | EXP-FW-V1-27 |
| 论文的 δd 是**精确**最坏穿透量，不是近似 | 相对偏差 0.0000 | A | EXP-FW-V1-21 |
| 沿风向余量**恒等于一个转弯半径**，与风速无关 | 余量 41.25 m，w = 0.1–0.5 不变 | A | EXP-FW-V1-22 |

## 与已有工作的关系（必须说清，否则会被反驳）

- **延迟距离概念并非本项目首次提出。** Thomas & Sarhadi (2024, *Machines*) 已给出
  经验形式 `s_t = V·t_c`（`t_c` 由滚转响应 rise time 定）。**差异**：它是经验标定
  （"must be tailored for each vehicle"）、**不含风**、且**正比于空速**；
  本构造下的是精确闭式、含风、**与空速无关**。
- **Kim et al. (2022, DASC)** 摘要自称缓冲尺寸可"verified"并"statistically guarantee"。
  **其全文未获取（付费）**，因此本项目的立项表述限定为
  "**该构造的充分性未被检验**"，不扩展为"风下缓冲充分性无人验证"。

## 两次被撤回的记录（保留，不删除）

1. **EXP-FW-V1-20** 曾报告"临界风速比 w\* ≈ 0.32，超过后缓冲不足"。
   该结论在 EXP-FW-V1-21 中被**撤回**（机动时长设为完整转弯周期，判据 artifact），
   修正后缺口消失。
2. **EXP-FW-V1-27 首次运行**曾报告"最坏构型为随机多边形、min margin = 0.1102 m"。
   经收敛性检验判定为**航向网格离散化伪影**（误差 O(1/N)，收敛到 0）。
   修订见 `experiments/EXP-FW-V1-27-preregistration-amendment-1.md`，**未覆盖原预注册**。

两次错误的过程与更正都保留在文件中——这是本项目规范的一部分
（见 `docs/CONVENTIONS.md` 第 5 节"失败保留"）。

## 诚实说明

- 全部为 3 自由度水平面点质量仿真；未含高度、气动、失速、滚转瞬态。
- 常值风；阵风、风切变、风估计误差、跟踪误差尚未处理。
- **仅凸多边形**；凹多边形与展平未测。
- "零冗余 → 任何未建模效应直接产生缺口"是**推论，等级 C**，未检验。
- 纯仿真；真机不作为结题前提（FW-D-002）。
- **本文档不主张该论文有误。** 我们检验的是一个重建的构造，结论是"此前未被验证"。
