## 1. 它做了什么

针对电子围栏（geofence）的分层缓冲，给出缓冲距离的**计算方法**：

1. 悬停能力机型：`δu = Va² / (2a)`（式 1，为减速停下的距离）。
2. 固定翼（有最小转弯半径）机型：`δu = Va / ω`（式 2），即**转弯半径**。
3. 方向缓冲 `δd`：把风下转弯轨迹写出来

   ```text
   x(t) = (Va/ω) sin(ωt) + Vw·t
   y(t) = −(Va/ω) cos(ωt)
   ```

   令 `ẋ(t) = 0` 得 `t* = (1/ω)·arccos(−Vw/Va)`，代入得

   ```text
   δd = (Va/ω)√(1 − Vw²/Va²) + (Vw/ω)·arccos(−Vw/Va)
   ```

   方向角 `φd` 取风向。

4. 然后用这套缓冲区去**缩放多边形围栏**，生成警告层与接管层，
   并要求缩放后的顶点与原始边界满足最小距离约束。

## 2. 量化：δd 有多大

记 w = Vw/Va，R = Va/ω（转弯半径）：

```text
δd/R = √(1 − w²) + w·arccos(−w)
```

| w | δd/R |
| --- | --- |
| 0.1 | 1.150 |
| 0.3 | 1.517 |
| 0.5 | 1.910 |

在取得 δd 的同一时刻，横向位移为 `R(1 + w)`（因为 cos(ωt*) = −w）。
于是该时刻飞机距出发点的位移：

```text
√(δd² + [R(1+w)]²)
```

w = 0.3 时 ≈ **2.00 R**。

## 3. 它的验证覆盖了什么（关键）

第 IV 节原文：

> "The first metric of success considered is the percentage of cases for which at least
> one smoothing setup resulted in a valid scaled layer."

蒙特卡洛设置：随机多边形（顶点在 [−50, 50] 内，随机旋转），
变量为顶点数（3–27）、δu（1/2/5/10）、δd（0, δu/2, δu），
共 3×10⁶ 个随机围栏，每个测 10 种分层设置。

也就是说，它验证的是：**算法能否为随机多边形生成满足缓冲距离约束的合法分层**。
这是一个**几何可行性**指标。

第 IV 节还写明：

> "Geofence boundaries are randomly generated without a directional bias, so the
> directional buffer angle φd is set to zero for all tests without loss of generality."

（这一条本身可以辩护：随机旋转的多边形等价于随机风向，对"成功率"这个指标而言确实不失一般性。）

## 4. 它没有验证什么（本项目的入口）

第 II 节给出了 δu 与 δd 的**推导**，第 IV 节给出了分层算法的**成功率**。
两者之间缺了一环：

> **没有任何实验检验"按 δu 与 δd 生成的分层，是否真的足以阻止一架有最小转弯半径的
> 固定翼飞机在有风条件下越界"。**

具体缺口有三条：

1. **缓冲区数值 vs 真实轨迹**：δd 是在"航向与风同向"这一特定构型下、
   对单次转弯求出的沿风向**一维**位移。真实可达集是二维的，
   且在取到 δd 的同一时刻横向位移已达 R(1+w) > δu = R。
   两者如何合成（δu 全向 + δd 单向）是否构成真实可达集的包含集，论文没有证明也没有测。
2. **不是只做整圈转弯**：飞机可能不需要完成整个转弯（部分转弯、连续转向的序列）。
3. **风是已知的**：δd 假设 Vw 精确已知，风估计误差的影响未考虑。

注意：第 III 节（分层生成算法）尚未逐行读，上述第 1 条是否已被第 III 节的构造处理，
必须读完第 III 节才能定论。**当前只能作为"待检验的缺口"，不是"论文的错误"。**

## 5. 对本项目的意义

v1.1 主线（地面系安全记账审计）**获得了第一个具体、可检验、有引文支撑的入口**：

> 已有的风下围栏/缓冲区方法，其缓冲数值被**推导**出来了，但其**充分性**没有被其自身或
> 后续工作验证过。

需要做的是：
1. 复现 δu、δd、φd 的构造（第 II 节 + 第 III 节）。
2. 计算真实的可达集 / 扫掠集（本项目已有的地面曲率工作是其基础）。
3. 检验包含关系：真实可达集 ⊆ 构造出的安全层？
4. 若否，给出精确的充分界（可能正是地面扫掠集包络）。
5. 若是，给出确认性结论与适用边界。

**两种结果都可发表**（见 `EXPERIMENT_STRATEGY.md` 第 5 节）。
