## 0. 背景

`LITERATURE_AUDIT_2026-09.md` 第 3.1 节曾断言：

> 如果 `F_future` 可以表示为**当前状态的函数**，那么 `J_total = J_now − λ·F_future`
> 与 `J_now` 产生完全相同的最优策略。

**该断言是错的。** 本文件给出反例，并给出修正后仍然成立的结论。

---

## 1. 断言 1（已撤回）：状态相关项 → 最优策略不变

**判定：假。**

反例（MDP，γ = 0.9，两个吸收状态动作）：

| 步骤 | 奖励设定 | V(s_A) | V(s_B) | Q(s₀,a₁) | Q(s₀,a₂) | 最优动作 |
| --- | --- | --- | --- | --- | --- | --- |
| 基线 | r_A = 10, r_B = 0 | 100 | 0 | 90 | 0 | **a₁** |
| 加入结果状态项 | r_A = −2, r_B = 0 | −20 | 0 | −18 | 0 | **a₂** |

策略从 a₁ 翻转为 a₂。故"状态相关项不改变最优策略"为假。

**精确表述（修正后）**：

1. 若该项只依赖**当前**状态 s_t，它对所有动作加上同一个常数，
   不改变 argmax，**但也因此无法区分动作——作为决策指标是无效的**。
2. 若该项依赖**结果**状态 s_{t+1}（即 F(a) = f(s_{t+1})），
   它是一般的状态奖励，**会**改变最优策略。这正是 `a_t → F_{t+1}` 的形式。
3. 仅当其恰好可写成势函数差分 `γΦ(s') − Φ(s)` 时，最优策略才不变。

**对项目的含义（正面）**：把 F_future 定义为"执行动作 a 后所得状态 s_{t+1} 的未来可行空间"
在决策上是**有效的**，不会被策略不变性吞掉。这一条按现在的写法**是安全的**。

## 2. 断言 2（保留，真但适用范围窄）：势函数塑形 → 策略不变

**判定：真。** 核验：`Q'(s₀,a) = Q(s₀,a) − Φ(s₀)`，数值偏差 0.000e+00，策略未变。

含义：只有当 F_future 被刻意构造成 `γΦ(s') − Φ(s)` 那种差分时，
future-aware planner 才退化为 myopic planner。这**不是**项目的风险，
但它是审稿人可能提出的一种等价化攻击，需要在论文里主动排除。

---

## 3. 断言 3（新增，可用结果）：约束型 ≠ 惩罚型，且差异是固定翼特异性

**这是本次核验真正有产出的部分。**

### 3.1 判据

比较两种决策规则：

- **惩罚型**：`argmin (J − λ·F)`，λ ≥ 0
- **约束型**：`argmin J s.t. F ≥ F_min`

判据不是"约束最优 ≠ 无约束惩罚最优"（二者本就不可比）。
正确判据是：**约束最优点是否为支撑点**——
即是否存在 λ ≥ 0 使该点在 `min(J − λF)` 处取得。

### 3.2 结果

| 算例 | 约束最优 (J, F) | 该点可支撑性 | Pareto 点中可支撑比例 |
| --- | --- | --- | --- |
| **固定翼式离散热机动集**（6 个动作，F_min = 60） | (9.00, 60.00) | **非支撑**（无任何 λ） | 2 / 4 |
| **类多旋翼凸权衡集**（J = F²/100，101 点，F_min = 60） | (36.00, 60.00) | λ ∈ (1.19, 1.21) | 101 / 101 |

### 3.3 解读

- **当权衡集非凸（离散机动集是典型情形）**，约束最优点可能落在 Pareto 前沿的
  "凹口"上，**任何惩罚权重都无法复现它**。此时"按未来可行空间约束来选动作"
  与"给当前代价加一项目标函数"是**两个不同的决策规则**，结论可以不同。
- **当权衡集凸（类多旋翼的连续权衡）**，约束最优点总是可支撑的，
  惩罚型可以复现约束型，二者等价。

### 3.4 为什么这是固定翼特异性现象（需进一步论证）

固定翼的机动集是**天然的离散/非凸**：
Dubins 路径构成的离散词表、最小转弯半径导致的不可达区域、
可达集在风场下的非凸变形。而多旋翼的机动集近似连续且凸（可悬停、可横移）。

**这一步是全项目的技术挡板**：它把"未来可行空间决策"与"奖励工程"区分开，
并且给出"换成四旋翼就不成立"的可检验理由。

**但必须承认的边界**：本核验是**构造的有限算例**，
不是一个一般性定理。要在论文里站住，需要：
(i) 证明固定翼机动集的非凸性是结构性的（而非本算例人为设定）；
(ii) 或给出"约束最优非支撑"的充分条件。

## 4. 对实验设计的直接约束（重要）

由断言 3 推出的硬约束：

> **若实验场景使权衡集近似凸，约束型与惩罚型会产生相同结果，**
> **实验必然测出"future-aware 无改善"，项目得到假阴性。**

因此 EXP 设计必须保证机动集**真的离散或非凸**：

- 使用离散机动词表（Dubins 路径族的有限子集），或
- 显式构造使可达集非凸的场景（狭窄通道、风场造成的可达域凹口），
- 并在预注册中**先验证**权衡集的非凸性（可行性检查），再比较决策规则。

否则整个实验的零结果无法区分"机制不存在"与"算例太滑"。

## 5. 与桌面文档四条链的关系

| 桌面文档写法 | 核验后的判定 |
| --- | --- |
| `J_total = J_now − λ·F_future`（奖励型） | **可用但不推荐**：会被审稿人以"奖励工程"质疑；风险是断言 2 的等价化攻击 |
| `argmin J s.t. F ≥ F_min`（约束型） | **推荐**：断言 3 给出了不可归约性，且不可归约性依赖固定翼机动集的非凸性 |

**建议的主线表述**：

> 固定翼的机动集是非凸的。因此"未来可行空间"作为**约束**进入决策时，
> 不能被任何惩罚权重等价替代；本工作量化这种不可归约性在何种条件下
> 改变实际决策，以及它多大地提升任务成功率。

## 6. 判据升级（2026-09-17，为 V2.0 设计）

脚本：`notes/verify_frontier_criterion.py`。本节把断言 3 从"有限算例"升级为**可判定判据**。

### 6.1 判据（已核验）

```text
动作 a 不可被任何 λ ≥ 0 的惩罚型规则复现
    ⟺  a 被可达 (J,F) 点集的**下凸包**跳过
推论 A：可达集凸 ⟹ 约束型 ≡ 惩罚型（任何 F_min）
推论 B：分歧区间 = 被跳过的 F_min 区间
```

核验：4000 组随机点集、6350 个 Pareto 点，判据 vs 暴力 λ 搜索 **零不一致**。

### 6.2 一次被否决的判据版本（保留记录）

第一版判据写作："该点处前沿**局部斜率**非递增（局部凹）即不可支撑"。
**被反例推翻**。反例（J, F）：

```text
(1.133,  9.231)   (7.968, 34.73)   (19.552, 46.294)   (21.062, 99.536)
局部斜率：        0.2681            1.0017             0.02836
```

第二个点 (7.968, 34.73) 满足"局部斜率递增"（0.2681 ≤ 1.0017），
但**不可支撑**：它要求 λ ≥ 0.2681，而最右点 (21.062, 99.536) 要求 λ ≤ 0.2021，区间为空。

**原因**：远端一个边际代价极低的点压低了 λ 的上界。
**结论**：不可支撑是**全局**性质，必须用凸包成员判定，不能看局部斜率。
这条否决记录决定了实现方式（必须做凸包，不能只查相邻斜率）。

### 6.3 一个双刃结果：混合会抹掉分歧

对同一非凸点集（F_min = 35）：

| 决策模型 | 最优 (J, F) | 可支撑 |
| --- | --- | --- |
| 单动作承诺 | (4.0, 35.0) | 否 |
| 允许混合（凸包松弛） | (2.69, 35.0) | 是 |

- 作为**机制**：分歧要求"确定性单动作承诺 + 非凸可达集"两者同时成立。
- 作为**风险**：审稿人可主张"分歧只是因为你禁止了随机化"。
  辩护需要论证 **F 对动作不可加**（凸组合不对应任何真实机动），
  故凸包松弛物理上不可达。**该辩护尚未完成**，属 G1/EXP-38 的内容。

### 6.4 引用义务（重要）

支撑点 / 非支撑点（supported vs unsupported efficient solutions）是
**多目标优化的教科书内容**。因此：

- **不得**声称首次发现"非凸前沿使惩罚法失效"；
- 必须在 G1 中补上该结论的精确原始引用；
- 本项目可主张的收窄为：固定翼非凸性的**结构性**、
  分歧区间的**量化**、对真实任务成功率的**影响**。
